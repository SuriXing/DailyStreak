# Flashcards｜几何

## 角、直线与基本图形

[核心][几何] 对顶角有什么关系？ :: 相等。
[核心][几何] 一条直线上的邻补角和是多少？ :: 180°。
[核心][几何] 点周围一周角是多少？ :: 360°。
[核心][几何] 平行线被截时有哪些常用角关系？ :: 同位角相等、内错角相等、同旁内角互补。
[核心][几何] 三角形内角和是多少？ :: 180°。
[核心][几何] 三角形外角定理是什么？ :: 一个外角等于两个不相邻内角之和。
[核心][几何] `n`边形内角和是多少？ :: `(n-2)·180°`。
[核心][几何] 任意凸多边形外角和是多少？ :: 360°。
[核心][几何] 正`n`边形每个内角是多少？ :: `(n-2)180°/n`。
[核心][几何] 正`n`边形每个外角/中心角是多少？ :: `360°/n`。
[核心][几何] 三角形不等式是什么？ :: 任意两边之和严格大于第三边。
[核心][几何] 两边固定时第三边`c`的范围是什么？ :: `|a-b|<c<a+b`。
[核心][几何] 等腰三角形的基本性质是什么？ :: 等边对等角；顶角平分线也是底边中线和高。
[核心][几何] 等边三角形的高和面积是什么？ :: 高`√3s/2`，面积`√3s²/4`。

## 全等、相似与三角形线段

[核心][几何] 三角形全等判定有哪些？ :: SSS、SAS、ASA、AAS，以及直角三角形HL。
[核心][几何] 为什么SSA通常不能判全等？ :: 可能存在两个不同三角形满足条件。
[核心][几何] 三角形相似判定有哪些？ :: AA（两角相等）、SAS（两边成比例且夹角相等）、SSS（三边成比例）。
[核心][几何] 相似比为`k`时周长比、面积比分别是什么？ :: `k`和`k²`。
[核心][几何] 相似立体线性比为`k`时表面积比、体积比是什么？ :: `k²`和`k³`。
[核心][几何] 三角形中位线定理是什么？ :: 连接两边中点的线段平行第三边且长度为其一半。
[核心][几何] 三角形中线是什么？ :: 顶点连接对边中点的线段。
[核心][几何] 重心如何分中线？ :: 从顶点到重心与重心到边中点之比为`2:1`。
[核心][几何] 角平分线定理是什么？ :: 内角平分线把对边分成邻边长度之比。
[核心][几何] 高是什么？ :: 从顶点向对边所在直线作的垂线段。
[提高][几何] 中线长度公式是什么？ :: `m_a²=(2b²+2c²-a²)/4`。
[提高][几何] Stewart定理描述什么？ :: 在△ABC中，D在BC上，BD=m、DC=n（a=m+n），AD=d，则b²m+c²n=a(d²+mn)；只在直接代入能明显缩短时用。
[核心][几何] 三角形重心是什么？ :: 三条中线的交点。
[核心][几何] 三角形内心是什么？ :: 三条内角平分线的交点。
[核心][几何] 三角形外心是什么？ :: 三边垂直平分线的交点。
[核心][几何] 三角形垂心是什么？ :: 三条高所在直线的交点。
[核心][几何] 内心到三边的距离有什么性质？ :: 相等，等于内切圆半径。
[核心][几何] 外心到三个顶点的距离有什么性质？ :: 相等，等于外接圆半径。
[核心][几何] 直角三角形外心在哪里？ :: 斜边中点。
[核心][几何] 直角三角形斜边中点性质是什么？ :: 到三个顶点距离相等，均为斜边一半。

## 面积与直角三角形

[核心][几何] 三角形面积基本公式是什么？ :: `K=bh/2`。
[核心][几何] 同高三角形面积比是什么？ :: 底边长度比。
[核心][几何] 同底三角形面积比是什么？ :: 高之比。
[核心][几何] 平行线之间同底三角形的面积关系是什么？ :: 高相同，因此面积相等。
[核心][几何] 勾股定理是什么？ :: 直角三角形两直角边平方和等于斜边平方。
[核心][几何] 勾股逆定理是什么？ :: 若最长边平方等于另两边平方和，则三角形为直角三角形。
[核心][几何] 常用勾股数组有哪些？ :: `3-4-5`、`5-12-13`、`7-24-25`、`8-15-17`及其倍数。
[提高][几何] 本原勾股数组参数式是什么？ :: m²-n²,2mn,m²+n²，其中m>n>0、gcd(m,n)=1且m、n一奇一偶。
[核心][几何] `45-45-90`三角形边比是什么？ :: `1:1:√2`。
[核心][几何] `30-60-90`三角形边比是什么？ :: `1:√3:2`，依次对30°、60°、90°。
[核心][几何] 直角三角形面积还可如何写？ :: 两直角边乘积的一半。
[核心][几何] Heron公式是什么？ :: `K=√[s(s-a)(s-b)(s-c)]`，`s=(a+b+c)/2`。
[提高][几何] 三角形面积与内切圆半径的关系是什么？ :: `K=rs`。
[提高][几何] 三角形面积与外接圆半径的关系是什么？ :: `K=abc/(4R)`；作为提高工具使用。
[核心][几何] 坐标平面两点距离公式是什么？ :: `√[(x₂-x₁)²+(y₂-y₁)²]`。
[核心][几何] 中点公式是什么？ :: `((x₁+x₂)/2,(y₁+y₂)/2)`。
[核心][几何] 斜率公式是什么？ :: `(y₂-y₁)/(x₂-x₁)`，竖直线斜率不存在。
[核心][几何] 两条非竖直平行线斜率有什么关系？ :: 相等。
[核心][几何] 两条非竖直互相垂直的直线斜率有什么关系？ :: 乘积为`-1`。
[提高][几何] 坐标多边形面积如何求？ :: 可切割、补形，或使用鞋带公式并取绝对值的一半。

## 四边形与多边形

[核心][几何] 平行四边形有哪些性质？ :: 对边平行且相等、对角相等、邻角互补、对角线互相平分。
[核心][几何] 矩形有哪些额外性质？ :: 四角为直角，对角线相等。
[核心][几何] 菱形有哪些额外性质？ :: 四边相等，对角线垂直且平分对角。
[核心][几何] 正方形兼具哪些性质？ :: 矩形与菱形的全部性质。
[核心][几何] 梯形中位线长度是什么？ :: 两底和的一半。
[核心][几何] 平行四边形面积是什么？ :: `底×高`。
[核心][几何] 梯形面积是什么？ :: `(上底+下底)×高/2`。
[核心][几何] 菱形/风筝用对角线求面积的公式是什么？ :: 垂直对角线乘积的一半。
[核心][几何] 正`n`边形如何分割求面积？ :: 分成`n`个以中心为顶点的全等等腰三角形。
[提高][几何] 正多边形面积与周长、边心距的关系是什么？ :: `K=(1/2)·周长·边心距`。
[提高][几何] 多边形对角线条数是多少？ :: `n(n-3)/2`。

## 圆

[核心][圆] 圆周长和面积公式是什么？ :: `2πr`和`πr²`。
[核心][圆] 弧长公式是什么？ :: `θ/360°·2πr`。
[核心][圆] 扇形面积公式是什么？ :: `θ/360°·πr²`。
[核心][圆] 同弧所对圆周角与圆心角关系是什么？ :: 圆周角是圆心角的一半。
[核心][圆] 直径所对圆周角是多少？ :: 90°。
[核心][圆] 同弧所对圆周角有什么关系？ :: 相等。
[核心][圆] 圆内接四边形对角关系是什么？ :: 对角互补。
[核心][圆] 半径与切线在切点处有什么关系？ :: 垂直。
[核心][圆] 同一外点引圆的两条切线段有什么关系？ :: 长度相等。
[核心][圆] 弦的垂直平分线经过哪里？ :: 圆心。
[核心][圆] 圆心到弦的垂线有什么性质？ :: 平分该弦。
[核心][圆] 两弦相交的幂定理是什么？ :: `PA·PB=PC·PD`。
[核心][圆] 割线—割线幂定理是什么？ :: 外部段×整条割线在两条割线上相等。
[核心][圆] 切线—割线幂定理是什么？ :: `切线长²=外部段×整条割线`。
[提高][圆] 相交弦形成的内部角如何求？ :: 角度为所截两弧度数和的一半。
[提高][圆] 圆外两割线/切线形成的角如何求？ :: 角度=(大弧−小弧)/2。
[核心][圆] 两圆外切时圆心距是什么？ :: 两半径之和。
[核心][圆] 两圆内切时圆心距是什么？ :: 两半径之差的绝对值。
[核心][圆] 相切圆题为什么先连圆心与切点？ :: 切点和圆心共线或形成半径垂线，可制造直角与确定距离。
[提高][圆] 弓形面积如何求？ :: 劣弧弓形=扇形面积−对应三角形面积；优弧弓形=扇形面积+对应三角形面积。
[提高][圆] 圆内接正多边形常用什么分割？ :: 从圆心连接顶点形成全等等腰三角形。

## 变换、轨迹与路径

[核心][变换] 平移保持哪些量？ :: 长度、角度、面积和方向。
[核心][变换] 旋转保持哪些量？ :: 长度、角度、面积；点到旋转中心距离不变。
[核心][变换] 反射保持哪些量？ :: 长度、角度、面积，但改变方向性。
[核心][变换] 位似倍率为`k`时长度和面积如何变化？ :: 长度乘`|k|`，面积乘`k²`。
[核心][变换] 关于x轴反射的坐标规则是什么？ :: `(x,y)→(x,-y)`。
[核心][变换] 关于y轴反射的坐标规则是什么？ :: `(x,y)→(-x,y)`。
[核心][变换] 关于原点旋转180°的规则是什么？ :: `(x,y)→(-x,-y)`。
[核心][变换] 绕原点逆时针90°的规则是什么？ :: `(x,y)→(-y,x)`。
[核心][轨迹] 到两定点距离相等的点的轨迹是什么？ :: 两点连线的垂直平分线。
[核心][轨迹] 到两相交直线距离相等的点的轨迹是什么？ :: 两条角平分线。
[核心][轨迹] 到定点距离固定的轨迹是什么？ :: 以该点为圆心的圆。
[核心][路径] 折线路径最短题常用什么方法？ :: 反射端点，把折线拉直为直线。
[提高][路径] 圆滚动无滑动时移动距离如何联系转角？ :: 轮心平移距离等于滚过弧长`rθ`。
[提高][几何] 几何题何时适合坐标化？ :: 有直角、平行、规则图形或距离条件，且能选出简洁坐标时。

## 立体几何

[核心][立体] 长方体体积是什么？ :: `lwh`。
[核心][立体] 长方体表面积是什么？ :: `2(lw+lh+wh)`。
[核心][立体] 棱柱体积是什么？ :: `底面积×高`。
[核心][立体] 棱锥体积是什么？ :: `底面积×高/3`。
[核心][立体] 圆柱体积是什么？ :: `πr²h`。
[核心][立体] 圆柱侧面积是什么？ :: `2πrh`。
[核心][立体] 圆锥体积是什么？ :: `πr²h/3`。
[核心][立体] 圆锥侧面积是什么？ :: `πrℓ`，其中`ℓ`为母线。
[核心][立体] 球体积是什么？ :: `4πr³/3`。
[核心][立体] 球表面积是什么？ :: `4πr²`。
[核心][立体] 体积守恒题的核心方程是什么？ :: 变化前后材料/液体总体积相等，注意溢出和空隙。
[核心][立体] 相似立体体积比如何由长度比得到？ :: 长度比的三次方。
[核心][立体] 长方体空间对角线是多少？ :: `√(l²+w²+h²)`。
[核心][立体] Euler多面体公式是什么？ :: 对凸多面体，`V-E+F=2`。
[提高][立体] 双计数多面体边的方法是什么？ :: 各面边数总和等于`2E`；各顶点度数总和也等于`2E`。
[提高][立体] 截面题的第一步是什么？ :: 确认截面与哪些棱/面相交，再用相似或坐标求边长。
[提高][立体] 展开图最短路径如何处理？ :: 展开相邻表面，把表面折线路径变成平面直线。
[提高][立体] 容器液面题需要警惕什么？ :: 容器形状变化时横截面积可能不恒定，不能总用高度成比例。
[边界][几何] AMC 10是否要求三角函数？ :: 官方范围排除三角学；特殊角用特殊三角形和几何关系处理。

## 查漏补充｜解析、格点与高频增强几何

[核心][坐标] 直线的斜截式是什么？ :: `y=mx+b`，适用于非竖直线。
[核心][坐标] 过点`(x₁,y₁)`、斜率为`m`的点斜式是什么？ :: `y-y₁=m(x-x₁)`。
[核心][坐标] 竖直线和水平线方程分别是什么？ :: `x=c`与`y=c`。
[核心][坐标] 圆的标准方程是什么？ :: `(x-h)²+(y-k)²=r²`，圆心`(h,k)`、半径`r`。
[核心][坐标] 点到水平/竖直直线的距离如何求？ :: 坐标差的绝对值。
[提高][坐标] 点到一般直线`Ax+By+C=0`的距离是什么？ :: `|Ax₀+By₀+C|/√(A²+B²)`。
[核心][坐标] 两向量的坐标加法表达什么？ :: 位移逐坐标相加；可处理连续平移和路径终点。
[提高][坐标] 两向量垂直的坐标判定是什么？ :: 点积`u₁v₁+u₂v₂=0`。
[提高][格点] Pick定理是什么？ :: 简单格点多边形面积`A=I+B/2-1`，`I`为内部格点数、`B`为边界格点数。
[提高][格点] 线段两端为格点时边界格点间隔数是什么？ :: `gcd(|Δx|,|Δy|)`；含两端的格点数再加1。
[提高][几何] 共圆的常用判定有哪些？ :: 对角互补；或同弦等角且两点在弦同侧（异侧时两角互补）。
[提高][圆] 切线—弦定理是什么？ :: 切线与弦所成角等于该弦在圆周另一侧所对的圆周角。
[提高][圆] Ptolemy定理是什么？ :: 圆内接四边形两对角线乘积等于两组对边乘积之和。
[提高][圆] 两圆公共弦与圆心连线有什么关系？ :: 公共弦垂直于两圆圆心连线。
[提高][圆] 根轴思想是什么？ :: 对两圆幂相等的点构成一条直线，包含两圆交点的公共弦所在直线。
[提高][三角形] Ceva定理的用途是什么？ :: 判定三条塞瓦线共点：有向长度比乘积=1（含三线平行的情形）；用无向长度比时必须限定三点都在三边线段上。
[提高][三角形] Menelaus定理的用途是什么？ :: 判定一条直线与三角形三边或延长线的三个交点共线；需谨慎使用有向长度。
[提高][三角形] 中线为何把三角形面积二等分？ :: 两个子三角形共享同一高且底边相等。
[提高][几何] 面积比追踪的优先规则是什么？ :: 先找同高、同底，再找相似比平方，最后才计算具体长度。
[提高][正多边形] 正多边形能铺满某顶点的角度条件是什么？ :: 汇聚在该点的内角和必须为360°。
[提高][变换] 两次平行线反射的复合是什么？ :: 沿垂线方向平移，距离为两线间距的2倍。
[提高][变换] 两次相交线反射的复合是什么？ :: 绕交点旋转，旋转角为两线夹角的2倍。
[提高][变换] 为什么变换复合通常不可交换？ :: 先后顺序改变中间位置；应跟踪一般点验证。
[核心][立体] 组合立体表面积如何避免重复？ :: 各外露面面积相加，粘合面不计且通常需从两物体表面积各减一次。
[提高][立体] 轴对称圆锥/圆柱相切问题如何降维？ :: 取经过轴线的截面，化成三角形、矩形与内切圆问题。
[提高][立体] 相似容器液面高度与体积如何联系？ :: 若从顶点起截面保持相似，体积比等于对应高度比的三次方。
[提高][立体] 平行于棱锥底面的截面有什么性质？ :: 截面与底面相似，长度比等于顶点到截面的高度比。
[提高][立体] 多面体图距离是什么意思？ :: 把顶点与棱视为图，距离是沿棱走的最少边数，不是空间直线距离。
[提高][几何概率] 密度不均匀时还能直接用面积比吗？ :: 不能；只有选点关于面积均匀时才用面积比，分块常需用密度×面积作权重。
