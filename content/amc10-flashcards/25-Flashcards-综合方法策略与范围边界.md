# Flashcards｜综合方法、策略与范围边界

## 建模与综合方法
[核心][方法] “一个数的 3 倍比它的 5 倍少 14”，第一步做什么？ :: 设这个数为 `x`，把每句话译成等式：`3x=5x-14`，解得 `x=7`。文字题先定义变量、写清单位，再逐句翻译，别急着算。
[核心][方法] 题目说“图未按比例绘制”，且图上两边看着一样长，能判定相等吗？ :: 不能。重画清晰草图，把已知、等长、平行、直角标上去，只看标记不看目测；未标直角就不能当 90°。
[核心][方法] 把 1 到 9 分成两组、要求两组和相等，可能吗？ :: 不可能。总和 `45` 是奇数，而两组和相等意味着总和必为偶数——这就是不变量（和的奇偶）。
[核心][方法] 求正整数 `a+b=10` 时 `ab` 的最大值，对称性怎样省事？ :: 交换 `a`、`b` 不改变条件与目标，所以最值必然出现在对称点 `a=b=5`，得 25。对称性用来减少分类、锁定取等位置。
[核心][方法] 5 个正整数中任意三个之和都不超过 10，最大的数最大是多少？ :: 8。用极端原则：要让最大数 `M` 尽量大，其余 4 个数就取最小 `1,1,1,1`，于是 `1+1+M≤10`，得 `M≤8`，且 `(8,1,1,1,1)` 可达。
[核心][方法] 证明 `√2` 是无理数时，为什么一开始就假设 `p/q` 已是最简分数？ :: 反证法：假设 `√2=p/q` 且 `p,q` 互质，推出 `p²=2q²` 得 `p` 为偶数，进而 `q` 也为偶数，与互质矛盾。先取“最简”是为了让矛盾能在最后一步落地。
[核心][方法] 怎么证明 3×3 方格中最多只能选 5 个两两不相邻的格子？ :: 上界：把 8 个格子配成 4 组相邻对（如 (1,1)-(1,2)、(1,3)-(2,3)、(3,3)-(3,2)、(3,1)-(2,1)），每组最多选 1 个，再加剩下的中心格，得 `≤4+1=5`；构造：四角加中心正好 5 个。构造给得出、上界证明超不过，才算证完。
[核心][方法] 数列前几项是 1、2、4、8、16，下一项一定是 32 吗？ :: 不一定。圆上 n 个点两两连线分割区域的数目正是 1、2、4、8、16，但第 6 项是 31。小规模只用来发现模式或找反例，不能替代证明。
[核心][方法] 方程 `4^x=8` 该怎样用选项快速判断？ :: 选项简单时直接代回：`4^{3/2}=8`，只有 `3/2` 成立。逆解麻烦而选项干净时，代答案是省时的正解，但要逐个选项真代进去。
[核心][方法] 判断一个含参数的多项式恒等式，取特殊值能做什么、不能做什么？ :: 能快速排除错误选项（取 `x=0`、`1`、`-1` 试），不能证明恒等——要证明必须化简为同一条式子或覆盖全部取值。
[核心][方法] 求面积的题，选项里出现 `3π cm` 这样的量，说明什么？ :: 可直接排除：面积必须是长度单位的平方。维度分析专治单位或次数错误。
[提高][方法] 条件全是二次式时，为什么可以令某个量为 1？ :: 所有项同次数（齐次）时整体可按比例缩放，比值的答案不变，所以常令某个和或长度为 1 来简化。注意这会改变和式本身的数值，只对“比值型”目标安全。
[提高][方法] 求 `x+1/x`（`x>0`）的最小值，怎样一次把两件事都做完？ :: 下界：`x+1/x≥2√(x·1/x)=2`；取等实例：`x=1` 时取到 2。所以最小值是 2。只给下界不给取等例子，答案是不完整的。
[提高][方法] 看到 `(x-3)²+(y-4)²` 应该想到什么？ :: 把它读成点 `(x,y)` 到 `(3,4)` 的距离平方。出现距离根式、平方和、绝对值或固定和积，就是代数题几何化的信号。
[提高][方法] 正六边形内接于单位圆，边长是多少？怎样算最快？ :: 用坐标或把它分成 6 个等边三角形：半径即边长，所以边长为 1。大量直角、平行、比例或规则变换，就是几何题代数化的信号。
[核心][方法] 同一题既有坐标法又有相似三角形，怎么选？ :: 选条件少、计算短、验算清楚的那条：直角与规则图形多时坐标法稳，比例关系密集时相似更快。两条都列出来后，比较哪条中间步骤少。
## 英文触发词
[核心][英文] 题目问 “the number of whole numbers less than 4”，0 算不算？ :: 算，通常 `whole number` 含 0，答案是 4 个（0,1,2,3）而不是 3 个；`integer` 才是“整数”。两者都不能想当然，以题目定义为准。
[核心][英文] “the positive divisors of 6” 有几个？ :: 4 个：1、2、3、6。`positive` 不含 0，0 也不是任何正整数的约数。
[核心][英文] 用数字 1、2、3 组成三位数，题目写了 `distinct` 有什么区别？ :: 写了 `distinct` 就不能重复用数字，只有 `3!=6` 个；若允许重复则是 `3³=27` 个。看到 `distinct` 先划掉重复计数。
[核心][英文] “at least 2 of the 5” 对应的概率怎么算？ :: `at least 2` 即 `≥2`。抛 5 次均匀硬币至少 2 次正面：`1-P(0)-P(1)=1-1/32-5/32=13/16`。见到 `at least` 先想补事件。
[核心][英文] `no more than 3` 与 `no less than 3` 分别翻译成什么？ :: 不超过 `≤3`；不少于 `≥3`。中文里对应“至多/至少”，别把两者写反。
[核心][英文] “three consecutive integers have sum 42”，这三个数是多少？ :: 13、14、15（中间数 = 42/3 = 14）。`consecutive` 表示相邻差 1，设中间数为 `n` 最快。
[核心][英文] 12 的 `factors` 有几个？12 小于 50 的 `multiples` 有几个？ :: factors（因数）有 6 个：1,2,3,4,6,12；multiples（倍数）小于 50 的有 4 个：12,24,36,48。`factor/divisor` 是因数，`multiple` 是倍数，方向相反。
[核心][英文] `remainder` 的取值必须满足什么？`-1` 除以 7 的余数是几？ :: 余数满足 `0≤r<m`，所以 `-1` 除以 7 的余数是 6 而不是 `-1`。设 `n=7q+r` 时别忘了这个范围。
[核心][英文] 从 1 到 10 均匀随机取一个数，取到质数的概率是多少？ :: `chosen uniformly at random` 指每个基本结果等概率。质数是 2,3,5,7 共 4 个，概率 `4/10=2/5`。
[核心][英文] “取两次，without replacement，两次都是红”怎么算？袋中 3 红 2 蓝。 :: `3/5·2/4=3/10`。`without replacement` 表示不放回，第二次的数量要随之改变，因此两次不独立。
[核心][英文] `expected number` 是“最可能出现的数量”吗？ :: 不是。掷一个骰子的期望是 3.5，而 3.5 根本不是可能结果；期望是长期平均值。掷两个骰子的和期望是 7，恰好也是最可能值，这只是巧合。
[核心][英文] `tangent`、`secant`、`chord` 分别是什么？割线外段 4、内段 9 时切线多长？ :: 依次是切线、割线、弦。切线-割线定理：切线长²=外段×整段，`t²=4×9=36`，`t=6`。
[核心][英文] `circumcircle` 与 `incircle` 有什么区别？3-4-5 直角三角形的两个半径是多少？ :: `circumcircle` 是外接圆（过顶点），`incircle` 是内切圆（与三边相切）。3-4-5 直角三角形外接圆半径 `5/2=2.5`，内切圆半径 `(3+4-5)/2=1`。
[核心][英文] 线段两端为 `(0,0)` 与 `(4,0)`，`perpendicular bisector` 是什么？ :: 垂直平分线：`x=2`。求垂直平分线就是找“到两端距离相等”的点集，常用来定外心或圆心。
[核心][英文] `centroid`、`incenter`、`circumcenter`、`orthocenter` 分别是什么？ :: 重心（三中线交点）、内心（角平分线交点，内切圆圆心）、外心（垂直平分线交点，外接圆圆心）、垂心（三高交点）。3-4-5 直角三角形的内心到斜边距离是 1。
[核心][英文] `similar` 与 `congruent` 有什么不同？相似比 1:2 的面积比是多少？ :: `similar` 允许缩放，`congruent` 全等（形状大小都相同）。相似比 1:2 时面积比是 `1:4`，体积比是 `1:8`——按平方/立方放缩。
[核心][英文] “a figure is `inscribed in` a circle”是什么意思？能推出什么？ :: 图形的所有顶点都在圆上。由此直径所对的圆周角必为 90°，这是最常见的用法。
[核心][英文] “a circle is `inscribed in` a polygon”是什么意思？正三角形边长 6 时半径多少？ :: 圆与多边形的每一边都相切。正三角形内切圆半径 `r=a√3/6=√3`。别把 `inscribed in` 的两个方向记反：顶点在圆上/圆与边相切。
[核心][英文] “the `maximum possible` value”除了算界还要确认什么？ :: 还要确认这个界能被合法对象达到。例如三边为整数、周长为 12 的三角形，最大边最大是 5（`(5,4,3)` 合法；6 会违反 `6<6`）。
[核心][英文] 题目写 “not necessarily drawn to scale” 提醒了什么？ :: 不能靠目测判断长度、角度或相交位置；一切以标记和条件为准，这也是“图形题先重画”的直接理由。
## 考场执行
[核心][策略] AMC 10 整卷结构是什么？ :: 25 道五选一，通常 75 分钟，平均每题 3 分钟；当年规则仍需以 MAA 官网为准。
[核心][策略] 第一轮的目标是什么？ :: 把确定会做的题先拿到手，不追求做完。平均 3 分钟一题的前提下，让一道难题吞掉 10 分钟就等于主动放弃后面三道。
[核心][策略] 什么时候应该暂时跳过一道题？ :: 大约 2–3 分钟仍没有清晰进展、计算已经失控或还没识别出模型时。跳过是策略不是放弃，回头往往一眼就通。
[核心][策略] 涂卡前应检查什么？ :: 题号与选项是否错位、有没有整题漏涂、空题是否按既定策略处理。这些错误代价和算错一样，但完全可避免。
[核心][策略] 数值答案应做哪三项检查？ :: 符号、数量级、单位与范围。求长度得到负数、求人数得到 `0.3`，都说明前面某一步错了。
[核心][策略] 几何答案应做什么合理性检查？ :: 长度为正、角度在正确范围、三角形满足两边之和大于第三边、面积不超过容器。例如直角边算出 6 而斜边是 5，必错。
[核心][策略] 概率答案的范围是什么？期望也受这个范围限制吗？ :: 概率必须在 0 到 1 之间，算出 `1.2` 或 `-0.1` 立刻回查；期望不受此限制，期望可以是 3.5 甚至任意实数。
[核心][策略] 整数题最后要检查什么？ :: 正/非负要求、整除性、奇偶、取值范围，以及是否重复计数。题目问“正整数解”却得到 0 个或负数，要回头看边界。
[核心][策略] 错题至少应按哪些类别归档？ :: 知识漏洞、模型识别、计算失误、读题误解、时间管理。分类决定补救方式：模型识别要靠识别卡，计算失误只能靠流程和复核。
[核心][策略] 错题复测为什么不能只看答案？ :: 看得懂答案不等于能独立重建解法。要闭卷重做，并说出“这题的第一句话触发了我用哪个方法”，否则下次仍然卡在启动。
[核心][策略] 推荐的复测间隔是什么？ :: 大约 48 小时、7 天、21 天各一次，再按遗忘情况调整。间隔太密是短期记忆，太疏等于重学。
## 范围与优先级
[边界][范围] AMC 10 的核心数学范围是什么？ :: 初等代数、初等几何、初等数论、计数与概率，以及它们的综合题。范围外的工具不是不能用，而是不必先学。
[边界][范围] 微积分属于 AMC 10 必需范围吗？ :: 不属于。求极值用配方、AM-GM 或对称性就够了，导数只是可选捷径。
[边界][范围] 三角函数是否属于官方核心范围？ :: 不属于。需要的是特殊角的值（如 `sin30°=1/2`）和几何关系，不需要三角恒等变换与解三角形全套。
[边界][范围] 复数应该作为优先专题吗？ :: 不应。它不是 AMC 10 备考优先内容，除非个人想拓展。
[边界][范围] 高级不等式应该先于基础方法学吗？ :: 不应。顺序是 AM-GM、Cauchy、Titu、配方、三角不等式与取等检查，先把基础方法的取等条件练熟。
[边界][范围] Burnside 与生成函数是必须掌握的吗？ :: 不是。它们只是少量高难对称/计数题的提高工具，主体仍靠分类、容斥与递推。
[边界][范围] 近五年低频就等于不会考吗？ :: 不等于。频率只用来分配训练时间，不能用来删减考纲或押题。
[边界][范围] 只刷 Flashcards 能替代完整做题吗？ :: 不能。卡片负责记忆与识别，真题负责建模、计算和时间压力，两者缺一不可。
## 查漏补充｜逻辑、证明与卡片闭环
[核心][逻辑] 命题是什么？ :: 能明确判断真或假的陈述句。
[核心][逻辑] 命题`P`的否定是什么？ :: “`P`不成立”；否定必须覆盖`P`以外的全部情况。
[核心][逻辑] “所有对象都满足P”的否定是什么？ :: “至少存在一个对象不满足P”。
[核心][逻辑] “至少存在一个对象满足P”的否定是什么？ :: “所有对象都不满足P”。
[核心][逻辑] 蕴含`P→Q`什么时候为假？ :: 仅当`P`真而`Q`假。
[核心][逻辑] `P→Q`的逆命题是什么？ :: `Q→P`，不一定与原命题等价。
[核心][逻辑] `P→Q`的逆否命题是什么？ :: `非Q→非P`，与原命题等价。
[核心][逻辑] “P是Q的充分条件”是什么意思？ :: `P→Q`。
[核心][逻辑] “P是Q的必要条件”是什么意思？ :: `Q→P`。
[核心][逻辑] “当且仅当”要求证明什么？ :: 两个方向都成立。
[核心][逻辑] 一个反例能推翻什么？ :: “所有……都……”或“必然……”型全称命题。
[核心][逻辑] 一个例子能证明“可能”吗？ :: 能；但不能证明“总是”。
[核心][逻辑] 真假话题的稳健方法是什么？ :: 为每个人/陈述设真假状态，逐条翻译并排除矛盾。
[提高][逻辑] 自指陈述题先检查什么？ :: 假设它真或假是否分别自洽；不要凭语感判断。
[提高][逻辑] 信息推断题如何证明答案唯一？ :: 列出所有初始可能，逐条筛选，最后确认只剩一个。
[核心][证明] 直接证明的结构是什么？ :: 从已知出发，用定义和已知定理逐步推出结论。
[核心][证明] 分类证明怎样保证完整？ :: 分类条件互斥并覆盖所有可能，边界单独确认。
[提高][证明] 交换论证如何证明贪心选择不劣？ :: 把任一最优解的局部选择换成贪心选择，证明可行且目标不变差。
[提高][证明] 归纳法的两步是什么？ :: 验证基础情形；假设第`n`情形成立并推出第`n+1`情形。
[核心][策略] “会背公式但不会启动”应补哪类卡？ :: 补“题面结构→首选方法”的识别卡，而不是重复公式卡。
[核心][策略] 每张知识卡怎样连接做题？ :: 至少绑定一道例题/真题题号，并记录首次独立做对日期。
[核心][策略] 卡片回答到什么程度才算通过？ :: 不只说公式，还要说适用条件、取等/边界和一个典型触发词。
[核心][策略] 如何防止卡片过大？ :: 一张只问一个可独立判定的问题；定义、公式、条件、陷阱必要时拆开。
[核心][策略] 如何防止只会正向回忆？ :: 同一重要知识同时做“名称→公式”和“结构→方法”两种方向的卡。
