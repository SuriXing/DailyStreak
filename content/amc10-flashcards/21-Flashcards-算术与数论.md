# Flashcards｜算术与数论

## 数与运算

[核心][算术] 运算顺序是什么？ :: 括号→指数/根式→乘除→加减；同级从左到右。
[核心][算术] 分配律是什么？ :: `a(b+c)=ab+ac`；反向使用可提取公因式。
[核心][算术] 平方差公式是什么？ :: `a²-b²=(a-b)(a+b)`。
[核心][算术] 完全平方公式是什么？ :: `(a±b)²=a²±2ab+b²`。
[核心][算术] 绝对值`|x|`表示什么？ :: `x`到0的距离；永远非负。
[核心][算术] 科学记数法的标准形式是什么？ :: `a×10^n`，其中`1≤|a|<10`且`n`为整数。
[核心][算术] 比例`a/b=c/d`如何交叉相乘？ :: 在分母非零时得到`ad=bc`。
[核心][算术] 正比例和反比例的模型分别是什么？ :: 正比例y=kx；反比例y=k/x或xy=k（都要求k≠0，反比例还需x≠0）。
[核心][算术] 连续两次百分比变化能直接相加吗？ :: 通常不能；总倍率为各次倍率的乘积。
[核心][算术] 增长`r%`和减少`r%`的倍率是什么？ :: 分别为`1+r/100`和`1-r/100`。
[核心][算术] 先涨`r%`再跌`r%`会回到原值吗？ :: 不会；倍率是`1-(r/100)²`。
[核心][算术] 加权平均公式是什么？ :: `加权和/权重总和`。
[核心][算术] 平均数反推总和的方法是什么？ :: `总和=平均数×数据个数`。
[核心][算术] 两组数据合并平均数如何求？ :: `(n₁a₁+n₂a₂)/(n₁+n₂)`。
[核心][算术] 等路程往返、速度为`u,v`时平均速度是多少？ :: `2uv/(u+v)`，不是算术平均。
[核心][算术] 路程、速度、时间关系是什么？ :: `d=rt`；统一单位后再列式。
[核心][算术] 相向运动的相对速度是什么？ :: 两速度之和。
[核心][算术] 同向追及的相对速度是什么？ :: 较快速度减较慢速度。
[核心][算术] 工作率模型是什么？ :: `工作量=工作率×时间`；共同工作时工作率相加。
[核心][算术] 浓度模型的守恒量是什么？ :: 溶质质量；`浓度=溶质/混合物总量`。
[核心][算术] 比例尺放大`k`倍时长度、面积、体积如何变化？ :: 分别乘`k,k²,k³`。
[核心][算术] 量纲检查有什么用？ :: 检查相加量是否同单位、答案单位是否合理。
[核心][算术] 上下界估算的基本原则是什么？ :: 对正量按运算方向选择上下界，并在最后检查误差方向。
[提高][算术] 调和平均公式是什么？ :: 正数`x₁,...,x_n`的调和平均为`n/(Σ1/x_i)`。

## 整除、质数与因数

[核心][数论] `a|b`是什么意思？ :: 存在整数`k`使`b=ak`。
[核心][数论] 质数的定义是什么？ :: 大于1且正因数只有1和自身的整数；1不是质数。
[核心][数论] 唯一质因数分解定理说什么？ :: 每个大于1的整数都能唯一写成质数幂的乘积，忽略排列顺序。
[核心][数论] `gcd(a,b)`是什么？ :: 同时整除`a,b`的最大正整数。
[核心][数论] `lcm(a,b)`是什么？ :: 同时被`a,b`整除的最小正整数。
[核心][数论] gcd与lcm的乘积关系是什么？ :: 对正整数，`gcd(a,b)·lcm(a,b)=ab`。
[核心][数论] 欧几里得算法是什么？ :: `gcd(a,b)=gcd(b,a mod b)`，重复至余数为0。
[核心][数论] 若`n=p₁^a₁...p_k^a_k`，正约数个数是多少？ :: `(a₁+1)...(a_k+1)`。
[提高][数论] 若`n=p₁^a₁...p_k^a_k`，正约数和是多少？ :: `∏(1+p_i+...+p_i^{a_i})`。
[提高][数论] 正约数乘积是多少？ :: `n^{d(n)/2}`；完全平方时中间的`√n`单独配对也仍成立。
[核心][数论] 一个整数是完全平方的质因数条件是什么？ :: 每个质因数指数均为偶数。
[核心][数论] 一个整数是完全立方的质因数条件是什么？ :: 每个质因数指数均为3的倍数。
[核心][数论] 如何求使`n`乘上最小正整数后成为平方？ :: 把质因数分解中所有奇指数各补1。
[核心][数论] 被2整除的判定是什么？ :: 个位数字为偶数。
[核心][数论] 被3整除的判定是什么？ :: 各位数字和被3整除。
[核心][数论] 被4整除的判定是什么？ :: 末两位组成的数被4整除。
[核心][数论] 被5整除的判定是什么？ :: 个位为0或5。
[核心][数论] 被8整除的判定是什么？ :: 末三位组成的数被8整除。
[核心][数论] 被9整除的判定是什么？ :: 各位数字和被9整除。
[核心][数论] 被10整除的判定是什么？ :: 个位为0。
[核心][数论] 被11整除的判定是什么？ :: 奇数位数字和与偶数位数字和之差被11整除。
[核心][数论] 若质数`p|ab`，能推出什么？ :: `p|a`或`p|b`；这不能直接推广到合数。
[核心][数论] 两个整数互质是什么意思？ :: gcd为1；不要求两者都是质数。
[核心][数论] 连续整数的gcd有什么性质？ :: 相邻两个整数互质。
[提高][数论] `n!`中质数`p`的指数如何求？ :: `⌊n/p⌋+⌊n/p²⌋+...`。
[核心][数论] `n!`末尾0的个数如何求？ :: 求因子5的指数，因为因子2更多。
[核心][数论] 因数对最接近何处时和最小？ :: `√n`附近；整数题要实际检查相邻因数对。
[提高][数论] 平方差`a²-b²`可写成什么因数结构？ :: `(a-b)(a+b)`，两因数同奇偶。

## 同余与余数

[核心][数论] `a≡b (mod m)`是什么意思？ :: `m|(a-b)`，即两数除以`m`余数相同。
[核心][数论] 同余可以进行哪些基本运算？ :: 可同模相加、相减、相乘；幂只对非负整数次幂无条件成立，用负指数前必须先确认gcd(a,m)=1。
[核心][数论] 同余式能随意约分吗？ :: 不能；只有约去的数与模互质，或同时正确缩小模数时才安全。
[核心][数论] 求大幂末位的常用方法是什么？ :: 对模10观察幂的周期。
[核心][数论] 求末两位应使用什么模？ :: 模100。
[核心][数论] 为什么先缩小底数再乘方？ :: 若`a≡r (mod m)`，则`a^n≡r^n (mod m)`，计算更小。
[核心][数论] 奇偶性对应什么模？ :: 模2。
[核心][数论] 平方数模4可能是什么？ :: 0或1。
[核心][数论] 平方数模8可能是什么？ :: 0、1或4；奇数平方模8为1。
[核心][数论] 平方数模3可能是什么？ :: 0或1。
[核心][数论] 数字和为什么能判断模9？ :: `10≡1 (mod 9)`，所以原数与数字和同余。
[提高][数论] 交错数字和为什么能判断模11？ :: `10≡-1 (mod 11)`。
[核心][数论] 线性同余`ax≡b (mod m)`何时有解？ :: 当且仅当`gcd(a,m)|b`。
[提高][数论] 当`gcd(a,m)=1`时如何解`ax≡b`？ :: 求`a`的模逆元，再两边乘逆元。
[提高][数论] 多个互质模条件如何处理？ :: 可逐步列候选或使用中国剩余思想合并周期；AMC 10通常不需背一般公式。
[核心][数论] 周期题第一步是什么？ :: 写出足够多项，确认起点、周期长度和索引偏移。

## 进制、数字与整数方程

[核心][数论] `b`进制数`(a_na_{n-1}...a_0)_b`的值是什么？ :: `Σa_i b^i`，且每位满足`0≤a_i<b`。
[核心][数论] 如何把十进制整数转成`b`进制？ :: 反复除以`b`并倒序读取余数。
[核心][数论] 一个`n`位`b`进制正整数的范围是什么？ :: `b^{n-1}`到`b^n-1`。
[核心][数论] 两位数`10a+b`倒序后是什么？ :: `10b+a`；两者差为`9(a-b)`。
[核心][数论] 三位数`100a+10b+c`如何翻译？ :: 按位值直接写，首位`a≠0`。
[核心][数论] 数字构造题最常漏掉什么？ :: 首位不能为0、数字是否可重复、位数和进制范围。
[核心][数论] 线性不定方程`ax+by=c`何时有整数解？ :: 当且仅当`gcd(a,b)|c`。
[核心][数论] 如何参数化线性不定方程的全部整数解？ :: 从一个特解出发，`x=x₀+(b/g)t,y=y₀-(a/g)t`，其中`g=gcd(a,b)`。
[核心][数论] 正整数解与非负整数解的区别是什么？ :: 正整数至少为1；非负整数允许0，参数范围不同。
[提高][数论] Frobenius两数结论是什么？ :: 互质正整数`a,b`不能表示为`ax+by`的最大非负目标数是`ab-a-b`；只在条件吻合时用。
[核心][数论] 有理根定理的基础版本是什么？ :: 整系数首一多项式的整数根必须整除常数项。
[提高][数论] 整值条件常如何转化？ :: 用带余除法、因式分解或同余把分母整除分子写出来。
[核心][数论] 证明不存在整数解的常用工具是什么？ :: 奇偶、模3/4/8/9、平方余数或因数奇偶性。
[提高][数论] `xy`为完全平方能否推出`x,y`都是平方？ :: 不能；只能说明两者各质因数指数奇偶性相同部分可配对。

## 查漏补充｜应用、统计与进阶数论

[核心][算术] 百分点与百分比变化有什么区别？ :: 从40%到50%是增加10个百分点，相对原值增加25%。
[核心][算术] 单利模型是什么？ :: 本息和`A=P(1+rt)`；每期利息只按原本金计算。
[提高][算术] 复利模型是什么？ :: 每期复利：期利率r、n期，A=P(1+r)^n；年名义利率r、每年复利m次、t年，A=P(1+r/m)^{mt}。两式r含义不同，n与t单位也不同。
[核心][算术] 利润与利润率如何计算？ :: `利润=售价-成本`；利润率的分母必须按题意确认，通常相对成本。
[核心][算术] 流水行船的顺流、逆流速度是什么？ :: `船静水速度±水流速度`。
[核心][算术] 环形跑道追及如何建模？ :: 同起点同向首次追上需弥补一圈，时间=圈长/速度差；起点相距g时时间=g/速度差；反向相遇用速度和。
[核心][算术] 中位数是什么？ :: 排序后居中的数；数据个数为偶数时取中间两数平均。
[核心][算术] 众数是什么？ :: 出现次数最多的数；可能没有或不止一个。
[核心][算术] 极差是什么？ :: 最大值减最小值。
[核心][算术] 加入一个新数据后平均数如何更新？ :: 先用旧平均数恢复旧总和，加新数后除以新个数。
[核心][数论] 一个区间内`d`的倍数个数如何求？ :: `1..N`中为`⌊N/d⌋`；区间`[L,R]`中为`⌊R/d⌋-⌊(L-1)/d⌋`。
[核心][数论] 能同时被`a,b`整除等价于什么？ :: 能被`lcm(a,b)`整除。
[核心][数论] 能被`a`或`b`整除的数量如何避免重复？ :: 两类相加，再减去`lcm(a,b)`的倍数数量。
[核心][数论] 被6整除的判定是什么？ :: 同时被2和3整除。
[核心][数论] 被12整除的判定是什么？ :: 同时被3和4整除。
[核心][数论] 有限小数的最简分母有什么特征？ :: 质因数只能有2和5。
[提高][数论] 循环小数如何转成分数？ :: 设变量后乘适当的10次幂，使循环部分对齐相减。
[核心][数论] 有理数与无理数的根式识别是什么？ :: 整数`n≥0`的`√n`仅在`n`为完全平方时是整数/有理数。
[提高][数论] 平方自由部分是什么？ :: 从质因数分解中去掉所有偶数次幂后剩余的乘积；用于合并和比较根式。
[提高][数论] `⌊√n⌋=k`等价于什么？ :: `k²≤n<(k+1)²`。
[提高][数论] Fermat小定理是什么？ :: 质数`p`且`p∤a`时，`a^{p-1}≡1 (mod p)`。
[提高][数论] Euler定理是什么？ :: `gcd(a,n)=1`时，`a^{φ(n)}≡1 (mod n)`。
[提高][数论] Euler函数`φ(n)`表示什么？ :: `1..n`中与`n`互质的整数个数；若`n=∏p_i^{a_i}`，则`φ(n)=n∏(1-1/p_i)`。
[提高][数论] 中国剩余思想何时有唯一周期解？ :: 模数两两互质时，联立同余在模数乘积意义下有唯一解。
[提高][数论] 为什么使用Fermat/Euler前必须检查互质？ :: 底数被模数的质因子整除时，指数降周期结论可能失效。
[提高][数论] `p`进赋值`v_p(n)`是什么？ :: 质数`p`在`n`的质因数分解中的指数；乘法相加、整除比较指数。
[提高][数论] 整数多项式输入同余时输出有什么关系？ :: 若`a≡b (mod m)`，则整系数多项式满足`P(a)≡P(b) (mod m)`。
[提高][数论] 随机选一个正约数时如何描述约数？ :: 把每个质因数指数在`0..a_i`间选择；所有约数等可能时指数向量等可能。
