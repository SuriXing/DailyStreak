# Flashcards｜组合、概率、期望与随机过程

## 计数基础

[核心][组合] 去 A 镇可以坐 3 班车或 4 趟火车（中途不换乘），总数为什么是 3+4 而不是 3×4？ :: “或/要么…要么”表示互斥情形，相加：3+4=7。出现“先…再…”或“每一步都要选一个”才用乘法。
[核心][组合] 3 件上衣配 4 条裤子有几种搭配？为什么不是 3+4？ :: 分两步完成（先上衣、再裤子）且每一步的选择数固定，3×4=12；只有互斥的“或”才相加。
[核心][组合] 从 5 人中“选 3 人排队”与“选 3 人开会”，结果差多少？ :: 排队 5·4·3=60，开会 `C(5,3)=10`，差 6=3!。同一批对象：有序用排列、无序用组合，先判断顺序是否算不同。
[核心][组合] 5 人排队有多少种排法？`0!` 为什么等于 1？ :: `5!=120`；`0!` 表示“从 0 个对象里排出 0 个”，只有一种空排列，也让 `C(n,n)=1` 与公式自洽。
[核心][组合] 8 人参赛取前 3 名（名次有区别）有几种结果？ :: `P(8,3)=8·7·6=336`。名次有区别=有序，取走一个就少一个，所以依次递减相乘。
[核心][组合] 8 人中选 3 人去值日有几种选法？ :: `C(8,3)=56`。无顺序，要把 3! 种内部排列除回去：336÷6=56。
[核心][组合] 要算 `C(10,8)`，怎样最快？ :: 用 `C(n,r)=C(n,n-r)`：`C(10,8)=C(10,2)=45`，把“选 8 个”换成“不选 2 个”。
[核心][组合] 不用计算器，怎样由 `C(8,·)` 得到 `C(9,3)`？ :: Pascal 恒等式：`C(9,3)=C(8,2)+C(8,3)=28+56=84`，含义是“含某个特定元素”与“不含它”两类。
[核心][组合] 6 个元素的集合有多少个子集？ :: 每个元素“选或不选”两种，共 `2^6=64`，也等于 `ΣC(6,r)=1+6+15+20+15+6+1`。
[核心][组合] MISSISSIPPI 这 11 个字母能排出多少种不同的串？ :: `11!/(4!4!2!)=34650`：除以同字母内部交换数（4 个 S、4 个 I、2 个 P），否则同一串被重复计数。
[核心][组合] 6 人围圆桌而坐（只把旋转视为相同）有几种坐法？ :: `(6-1)!=120`。直线排列是 `6!=720`，相差 6=人数；固定一个人当参照就退化成直线排列。
[提高][组合] 2 色 6 珠的手链，只算旋转得 14 种；若反射也算相同，能直接除以 2 吗？ :: 不能得 7，正确是 13。因为有些串在反射下自己不动（如左右对称的串），单纯除 2 会把它们多减；应按每个对称操作数“不动的构型”再平均。
[核心][组合] 掷 3 个骰子“至少一个 6”的概率怎样算最快？ :: 用补集：`1-(5/6)^3=91/216≈0.421`。直接按“恰好 1 个、2 个、3 个 6”分类要分三种且容易漏。
[核心][组合] 1 到 100 中能被 3 或 5 整除的数有几个？ :: `33+20-6=47`：减去 15 的倍数（6 个），因为它们在两个集合里各被数了一次。
[提高][组合] 1 到 100 中能被 2 或 3 或 5 整除的数有几个？ :: `50+33+20-(16+10+6)+3=74`：单集加、两两交减、三交加，符号交替，漏掉最后一项就会少算 3 个（30 的倍数）。
[核心][组合] 把 5 个相同球分给 2 人时，“第一人至少 1 个”与“第一人 0 个”这两类够用吗？ :: 够：两类互斥且合起来是全部。若改成“第一人至少 1 个”与“第二人至少 1 个”就出现重叠（如 1+4），会重复计数。
[核心][组合] 圆桌 6 人为什么可以固定 1 人当参照？ :: 固定一人即消除旋转造成的重复，余下 5 人做直线排列，得 `(6-1)!=120`。遇到对称或邻接限制，先固定特殊对象往往能直接消掉重复。
[核心][组合] 5 人排队、甲乙必须相邻，有几种排法？ :: 把甲乙捆成一块：`4!×2!=48`。出现“必须相邻”就用捆绑法，别忘了乘块内 2!。
[核心][组合] 5 个 A 与 3 个 B 排成一排、要求 B 互不相邻，有几种？ :: 先排 5 个 A 形成 6 个空位，再选 3 个放 B：`C(6,3)=20`。同类元素相同，不用再乘 3!；若 A、B 各自不同则还要乘内部排列。
[核心][组合] 10 块相同的糖分给 3 个小朋友（允许有人没有）有几种分法？ :: 星与条：`C(10+3-1,3-1)=C(12,2)=66`。物品相同、盒子不同就用这个模型；盒子不同才有标号。
[核心][组合] `x+y+z=10` 的非负整数解有几个？ :: `C(12,2)=66`，与“10 个相同球分入 3 个不同盒子”是同一件事。
[核心][组合] `x+y+z=10` 的正整数解有几个？ :: 先给每个变量 1（用掉 3），剩余 7 自由分配：`C(9,2)=36`。正整数解要求 `n≥k`，否则无解。
[核心][组合] `x+y+z=10` 且每个变量不超过 5，解数是多少？能直接套 `C(12,2)` 吗？ :: 不能，要容斥：`66-3·C(6,2)=66-45=21`（某变量≥6 时令它减 6，剩 4 分给 3 个变量）。两个变量同时超界不可能，所以无需加回。
[提高][组合] 用 0–9 十个数字（不重复）组成三位偶数，有多少个？ :: 按末位分类：末位为 0 时 `9×8=72`；末位是 2/4/6/8 时首位不能为 0，`4×8×8=256`；共 328。首位与末位的限制必须分开处理。
[提高][组合] 从 1–9 中选 3 个数字排成严格递增的三位数，有多少个？ :: 每个选出的集合只有一种递增排法，所以等于 `C(9,3)=84`。若允许相等，就变成多重组合 `C(9+3-1,3)`。

## 结构计数与证明

[核心][组合] 抽屉里有 4 种颜色的袜子，至少取几只才能保证有一双同色？ :: 5 只。最坏情况前 4 只各一色，第 5 只必与其中一只同色（`n+1` 个对象入 `n` 个盒子）。
[核心][组合] 8 人两两握手一次，用两种方式数会得到什么等式？ :: 按人算：每人 7 次共 56，每场握了 2 次；按场算：`2·C(8,2)=56`，得 `C(8,2)=28`。把同一批对象用两种方式数就是双计数。
[核心][组合] 能否让 7 个人每人恰好握 3 次手？ :: 不能。总度数为 `7×3=21` 是奇数，而每条边贡献 2，总和必须为偶数（握手定理）。
[核心][组合] 10 个顶点的连通无环图有几条边？ :: 9 条：`V-1`。树连通又无环，每加入一个顶点恰好加一条边。
[提高][组合] 4 列 3 行的方格网，从左下角走到右上角的最短路径有几条？ :: `C(a+b,a)=C(7,4)=35`：路径由 4 步向右、3 步向上构成，只需决定哪几步向右。
[核心][组合] 一段楼梯每次跨 1 级或 2 级，上 6 级有几种走法？ :: `a_n=a_{n-1}+a_{n-2}`，`a_1=1,a_2=2`，得 13。按“最后一步跨几级”分类最直接。
[核心][组合] 统计长度为 5 的 01 串中“没有相邻两个 1”的个数，递推状态要记什么？ :: 只记最后一位是 0 还是 1（它决定下一步是否受限），共 13 个。状态设计的原则是只保留决定下一步的最少信息。
[提高][组合] 8×8 棋盘剪掉两个对角格后，能用 31 张 1×2 骨牌铺满吗？ :: 不能。棋盘原有 32 黑 32 白，剪掉的两个对角格同色，剩下 30/32；而每张骨牌必盖一黑一白，要求两色数量相等。
[提高][组合] 黑板上写着 9、5、2，每次把最大的数换成另外两数之差的绝对值，这个过程会一直进行下去吗？ :: 不会：`(9,5,2)→(5,3,2)→(3,2,1)→(2,1,1)→(1,1,0)`，之后状态不再改变。因为新值 `|x-y|` 不会超过原来的最大数，总和单调不增，最终只能停在 `(k,k,0)` 形态。注意这里只能断定“不增并稳定”，说成“严格递减”是错的——`(1,1,0)` 就是反例。
[核心][组合] 要证明“n 个点最多 `C(n,2)` 条边”，需要写哪两步？ :: ①构造：每两点连一条，达到 `C(n,2)`；②上界：每条边对应一对点，而点对总数只有 `C(n,2)`。构造给得出、上界证明超不过，合起来才算极值证明。
[提高][组合] `{2,3,5}` 与 `{1,4,6,9}` 哪个是 sum-free 集合？ :: `{2,3,5}` 不是，因为 `2+3=5` 仍在集合内；`{1,4,6,9}` 是，任意两数（可相同）之和都不在其中。审题要先确认是否允许 `x=y`。
[提高][组合] 用黑白两色给 1×4 的格子染色且相邻不同色，有几种？ :: 2 种。第一格定下后其余唯一确定；若颜色有标签（“黑”与“白”不同）则第一格有 2 选，答案翻倍，染色题先问颜色是否等价。
[提高][组合] 数“本质不同”的 2×2 黑白染色图案，第一步做什么？ :: 先列出被视为相同的操作集（正方形的 8 个对称：4 个旋转+4 个翻折），再看哪些图案被它们互相转化。不先定操作集，就会把同一个图案重复计入。
[提高][组合] 用两色给正方形的 4 个顶点染色（旋转与翻折都算相同），有几种？ :: 按每个对称操作数不动的构型再平均：`(16+2+4+2+4+4+8+8)/8=6`。恒等 16；旋转 90°/270° 各固定 2；旋转 180° 固定 4；两条对角线翻折各固定 4；两条中位线翻折各固定 8。AMC 10 只在直接分类很乱时才用它。
[提高][组合] “1–100 中不含数字 7 的数”与“5 个字母要求某两个不相邻”，哪个用容斥、哪个用递推？ :: 前者是全局禁止（每个位置的限制互相纠缠），用按位分类或补集；后者是局部相邻限制，用递推或插空。全局禁止→容斥，局部相邻→递推/插空。

## 概率

[核心][概率] 掷两个骰子，点数和为 7 的概率是多少？ :: `6/36=1/6`：有利结果有 (1,6)…(6,1) 六种。两骰有序，别把 (1,6) 与 (6,1) 当成同一个结果。
[核心][概率] 为什么不能把“两骰点数和为 2 到 12”的 11 种和当作等可能？ :: 各和对应的有序结果数不同（和 7 有 6 种，和 2 只有 1 种）。“有利数/总数”只在基本结果等可能时成立，先确认等可能再套公式。
[核心][概率] 掷 3 枚硬币“至少一个正面”的概率？ :: `1-P(全反)=1-1/8=7/8`。见到“至少”先想补事件。
[核心][概率] 已知 `P(A)=0.5`、`P(B)=0.4`、`P(A∩B)=0.2`，`P(A∪B)` 是多少？ :: `0.5+0.4-0.2=0.7`。直接相加会把交集算两次，必须减掉一次。
[核心][概率] 袋中 3 红 2 蓝，无放回取两次，已知第一次是红，第二次也是红的概率？ :: `2/4=1/2`：条件把样本空间缩到“第一次红”的情形里重新计数，等价于 `P(A∩B)/P(B)=(3/5·2/4)/(3/5)`。
[核心][概率] 掷两个独立骰子时 `P(都是 6)` 能直接相乘吗？依据是什么？ :: 能：`1/36=1/6·1/6`，这正是独立的定义 `P(A∩B)=P(A)P(B)`。一般事件必须用条件概率 `P(A)P(B|A)`。
[核心][概率] 掷一次骰子，“得 1”与“得 2”互斥吗？独立吗？ :: 互斥（不能同时发生），但不独立：一个发生会让另一个的概率变成 0。正概率的互斥事件一定不独立，两个词不能混用。
[核心][概率] 52 张牌连抽两张都是 A 的概率，为什么不是 `(4/52)²`？ :: 无放回时第二次只剩 3 张 A、51 张牌：`4/52·3/51=1/221`。前一次结果改变了后一次的样本空间，所以不独立。
[核心][概率] 某射手命中率 1/3，连射 3 次至少命中一次的概率？ :: `1-(2/3)^3=19/27≈0.704`。只有各次独立，才能把“全不中”的概率直接乘起来。
[核心][概率] 抛 5 次均匀硬币，恰好 3 次正面的概率？ :: `C(5,3)(1/2)^5=10/32=5/16`：先选哪 3 次是正面（组合），再乘每一种顺序的概率。
[核心][概率] 随机选一箱：箱 A（被选概率 1/3）有 3 红 2 蓝，箱 B 有 1 红 4 蓝；取到红球的概率？ :: `1/3·3/5+2/3·1/5=1/3`。按互斥完备的情形分解目标概率再加权，前提是先把所有能产生目标结果的路径列全。
[提高][概率] 患病率 1%，检测灵敏度 99%、假阳性 5%，检出阳性的人真患病的概率是多少？ :: `0.0099/(0.0099+0.0495)=1/6≈16.7%`。分母包含所有产生阳性的路径（大量健康人的假阳性），只看 99% 会把答案高估到接近 1。
[核心][概率] 100 人中有 40 名男生，其中 10 人戴眼镜；已知选到的是男生，他戴眼镜的概率？ :: `10/40=1/4`。条件把样本空间从 100 人缩到 40 人，分子分母都要跟着换。
[核心][概率] 7 人随机排队，甲恰好站在第 3 位的概率？ :: `1/7`。由对称性，甲落在任意位置等可能，不必去算 `6!/7!`。
[核心][概率] 5 人随机排队，甲乙相邻的概率？ :: `2/5`。把甲乙捆成一块（2! 种）与其余 3 人共 `4! ` 种，除以 `5!` 得 `2/5`；对任意 `n` 人都是 `2/n`。
[提高][概率] 在单位正方形内均匀取点，它到原点距离小于 1 的概率？ :: `π/4≈0.785`：有利区域是以原点为心、半径 1 的四分之一圆。面积模型中概率等于有利面积除以总面积。
[核心][概率] “先均匀取半径、再均匀取角度”得到的点，与“圆盘内均匀取点”相同吗？ :: 不同。圆盘内均匀时半径密度是 `2r`（越往外环面积越大），按半径均匀取会让内圈偏多。随机机制决定密度，题目必须先说清怎么取。
[提高][概率] 在正方形内均匀取一点，它恰好落在指定对角线上（或恰好距离为 1）的概率？ :: 0：直线与圆周的面积都是 0。但边界仍用来划分区域（求“≥1”或“≤1”时必须靠它），所以不能因为概率为 0 就忽略。

## 期望

[核心][期望] 掷一个均匀骰子的期望是多少？ :: `(1+2+…+6)/6=3.5`：按每个取值乘它的概率求和，是加权平均。
[核心][期望] 掷一次骰子能掷出 3.5 吗？那期望还有什么用？ :: 不能。期望是长期平均：掷很多次后平均值趋近 3.5。期望不必是可能出现的结果。
[核心][期望] 已知 `E(X)=4`，`E(2X+3)` 是多少？ :: `2·4+3=11`。常数可以提出、可以相加，完全不需要知道 X 的分布。
[核心][期望] 同一副牌里第一张与第二张的点数期望能相加吗？需要独立吗？ :: 能。`E(X+Y)=E(X)+E(Y)` 对任何随机变量都成立，不要求独立——这是最容易误记成“需要独立”的公式。
[核心][期望] 怎样把“掷骰得偶数”这个事件写成随机变量？ :: 令 `I=1`（得偶数）、`I=0`（否则），则 `E(I)=P(偶数)=1/2`。指示变量的期望就是事件概率，这是它的全部用途。
[核心][期望] 抛 10 次硬币的正面次数 X，怎样用指示变量求 `E(X)`？ :: 写 `X=I_1+…+I_10`，每个 `E(I_i)=1/2`，相加得 5。不用先求 X 的分布。
[核心][期望] 把 5 个球随机放进 5 个标号盒（每盒一球），“球在对应编号盒”的个数期望？ :: 每个球设指示变量，概率 `1/5`，相加得 `5×1/5=1`。n 个对象随机排列的固定点数期望恒为 1。
[核心][期望] 10 个球独立随机放入 3 个盒子，“非空盒数”的期望是多少？ :: 对每个盒子设“非空”指示变量：`P(非空)=1-(2/3)^10`，所以期望是 `3[1-(2/3)^10]≈2.95`。空盒数的期望则是 `3(2/3)^10`。
[核心][期望] 公平地抛 6 次硬币，“HH”相邻对出现次数的期望？ :: 共有 5 个相邻位置，每个是 HH 的概率 `1/4`，相加得 `5/4=1.25`。这些位置并不独立，但期望线性不要求独立。
[提高][期望] 每次成功概率 1/4 的独立试验，首次成功所需次数 X 的期望用尾和怎样算？ :: `E(X)=Σ_{k≥1}P(X≥k)=Σ(3/4)^{k-1}=1/(1-3/4)=4`，与几何分布的 `1/p` 一致。尾和适合取正整数值的变量。
[提高][期望] 掷两个骰子取较大值的期望是多少？ :: 先算累积：`P(M≤m)=(m/6)²`，差分得 `P(M=m)=[m²-(m-1)²]/36`，求和得 `161/36≈4.47`。求最大值期望先算“≤”的累积更省事。
[提高][期望] 成功概率恒为 1/3、各次独立，首次成功平均需要几次？ :: `1/p=3`：写 `E=1+失败概率·E` 即可解出。若成功概率随轮次变化，必须改用带状态的方程 `E_s=1+ΣP(s→t)E_t`。

## 随机过程

[提高][随机过程] 掷硬币直到出现“正反”序列，平均要掷几次？第一步分析怎么写？ :: 按已匹配的前缀设未知量：`p_∅=1+½p_H+½p_∅`、`p_H=1+½p_H`（再抛正面仍停在 H），解得从空状态出发平均 4 次。关键是按“当前匹配到什么前缀”分类。
[提高][随机过程] 端点为 0 和 3 的公平随机游走，从 1 出发先到 3 的概率，第一步写什么？ :: 先写吸收边界 `P(0)=0`、`P(3)=1`，再写内部方程 `P(i)=½P(i-1)+½P(i+1)`，解得 `P(1)=1/3`。边界不写，方程就解不出确定值。
[提高][随机过程] 公平一维随机游走在两个吸收端点之间，先到右端的概率随起点怎样变化？ :: 线性变化（起点 i 在 0 与 N 之间）。端点值一旦确定就能直接插值，不必逐点解方程。
[提高][随机过程] 从 0 到 8 的公平随机游走，从 5 出发先到 8 的概率？ :: `i/N=5/8`。这是上一条线性结论的直接应用：起点越靠右，越容易先碰到右端。
[提高][随机过程] 用递推解出各状态概率后，要检查哪三件事？ :: ①每个概率都落在 0 与 1 之间；②吸收边界的取值符合题意（成功=1、失败=0）；③状态是否覆盖全部可能，遗漏状态会让方程无解或答案偏大。
[提高][概率] `P(A∩B)` 能直接写成 `P(A)P(B)` 吗？ :: 只有独立时才能。一般要用条件乘法 `P(A∩B)=P(A)P(B|A)`，相关事件（如连续两天下雨）直接相乘会算错。
[提高][概率] 3 个球随机放入 2 个盒子，(3,0) 与 (1,2) 这两种分布的概率一样吗？ :: 不一样。若球彼此独立地选盒，(3,0) 有 2 种结果、(1,2) 有 6 种，概率分别是 `2/8` 与 `6/8`。要按每个对象的等可能选择计数，不能把“人数分布”当等可能。
[提高][概率] 两个骰子的点数和 7 与 12，哪个更容易出现？ :: 和 7 有 6 种有序结果、和 12 只有 1 种，概率是 `6/36` 与 `1/36`。和值本身不等可能，中间的和更容易出现。

## 查漏补充｜近年结构与进阶计数概率

[核心][组合] 多项式系数/多类排列公式是什么？ :: 把`n`个不同位置分成大小`n₁,...,n_k`的有标号组，数量为`n!/(n₁!...n_k!)`。
[核心][组合] 有标号盒子与无标号盒子为什么不同？ :: 交换盒子若产生新结果则有标号；无标号分组需再处理组的交换重复。
[提高][组合] 把`n`个不同对象分成若干指定大小的无标号组怎样去重？ :: 先按有标号组计数，再除以大小相同的组之间的排列阶乘。
[提高][组合] 整数分拆与整数解有什么区别？ :: 分拆不计加数顺序；方程的有标号变量通常计顺序。
[核心][组合] 排列中的逆序对是什么？ :: 一对位置`i<j`却有`a_i>a_j`。
[提高][组合] 相邻交换会怎样改变逆序对数？ :: 恰好改变1，因此逆序对奇偶性翻转。
[核心][组合] `n`人循环赛每两人比赛一次共有多少场？ :: `C(n,2)`。
[提高][组合] 圆上`n`点无三弦共点时弦的内部交点数是多少？ :: 每4个点决定一个交点，所以为`C(n,4)`。
[提高][组合] 平面中若逐条加入曲线/直线，区域数如何递推？ :: 新曲线被已有交点分成几段，就新增几块区域；必须检查交点一般位置。
[提高][组合] 错排是什么？ :: 没有任何对象回到原位置的排列；小规模可容斥或递推。
[提高][组合] 错排递推是什么？ :: `D_n=(n-1)(D_{n-1}+D_{n-2})`，`D_0=1,D_1=0`。
[提高][组合] Catalan型结构的识别信号是什么？ :: 前缀始终不越界的路径、合法括号或非交叉结构；不是AMC 10基础必背。
[提高][组合] 反链是什么？ :: 集合族中任意两个集合都不互为包含；中间层常给最大构造。
[提高][组合] 排名允许并列时如何计数？ :: 先选并列分块/人员，再排列有序名次块；必须明确是否跳过后续名次。
[提高][组合] 局部染色如何建立状态？ :: 记录下一步仍会受影响的边界颜色/相等关系，不保存完整历史。
[核心][概率] 超几何概率描述什么？ :: 从含`K`个成功对象的`N`个对象中无放回取`n`个，恰好`k`个成功概率为`C(K,k)C(N-K,n-k)/C(N,n)`。
[提高][概率] 多项分配概率是什么？ :: 独立试验落入多类，计数为多项式系数乘各类概率的相应幂。
[核心][概率] 随机选一个约数时为什么不能按约数大小区间直接假设均匀？ :: 均匀的是约数列表中的对象；应先枚举质因数指数组合。
[提高][概率] 全概率公式是什么？ :: 对完备互斥事件`B_i`，`P(A)=ΣP(A|B_i)P(B_i)`。
[提高][概率] 条件期望的分层公式是什么？ :: `E(X)=ΣE(X|B_i)P(B_i)`。
[提高][期望] 期望乘积何时可拆？ :: `X,Y`独立时`E(XY)=E(X)E(Y)`；一般不能拆。
[提高][期望] 方差定义是什么？ :: `Var(X)=E[(X-E X)²]=E(X²)-[E(X)]²`。
[提高][期望] Bernoulli变量的期望与方差是什么？ :: 若成功概率`p`，则期望`p`、方差`p(1-p)`。
[提高][期望] 最小值的尾部如何处理？ :: 可由`P(min≥k)`求尾和，或先求最大/补变量的分布。
[提高][随机过程] 吸收时间期望的第一步方程是什么？ :: 非终止状态`E_s=1+ΣP(s→t)E_t`，终止状态期望为0。
[提高][随机过程] 状态具有对称性时如何降维？ :: 把未来行为完全相同的状态合并，写同一个未知量。
[提高][概率] 淘汰赛晋级概率如何递推？ :: 按下一场对手/胜负分类，将当前轮概率乘后续条件概率并相加。
[提高][概率] 条件概率中“已知最终成功”为什么会改变早期分支概率？ :: 不同早期分支通向最终成功的概率不同，需用Bayes重新加权。
