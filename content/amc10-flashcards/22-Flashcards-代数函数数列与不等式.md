# Flashcards｜代数、函数、数列与不等式

## 方程与代数式

[核心][代数] 解方程前为什么要写定义域？ :: 防止分母为0、偶次根号内为负及其他无意义值。
[核心][代数] 分式方程的标准流程是什么？ :: 写限制→乘最小公分母→解整式方程→验根。
[核心][代数] 根式方程为什么必须验根？ :: 平方可能引入增根。
[核心][代数] 二元一次方程组常用方法是什么？ :: 代入、消元，或用和差结构直接处理。
[核心][代数] 什么时候适合设总量为方便数字？ :: 只给比例或百分比且答案对尺度不敏感时。
[核心][代数] 代数换元的目标是什么？ :: 把重复结构视为一个变量，降低次数或减少项数。
[核心][代数] 对称式中常用的换元是什么？ :: `s=x+y,p=xy`。
[核心][代数] `x²+y²`如何用`s=x+y,p=xy`表示？ :: `s²-2p`。
[核心][代数] `x³+y³`如何表示？ :: `(x+y)³-3xy(x+y)=s³-3ps`。
[核心][代数] `1/x+1/y`如何合并？ :: `(x+y)/(xy)`，前提`xy≠0`。
[核心][代数] 绝对值方程`|x|=a`如何解？ :: `a<0`无解；`a=0`有`x=0`；`a>0`有`x=±a`。
[核心][代数] `|x-a|`的几何意义是什么？ :: 数轴上`x`到`a`的距离。
[核心][代数] 解多个绝对值表达式的可靠方法是什么？ :: 按所有临界点分区间，去绝对值后逐段验范围。
[核心][代数] 取整函数`⌊x⌋=n`等价于什么？ :: n≤x<n+1（n∈Z）。
[核心][代数] 上取整`⌈x⌉=n`等价于什么？ :: n-1<x≤n（n∈Z）。
[提高][代数] 含`⌊x⌋`方程为何要分整数部分和小数部分？ :: 写`x=n+r`，其中`n∈Z,0≤r<1`可固定跳变位置。

## 二次式与多项式

[核心][代数] 一元二次方程求根公式是什么？ :: `x=(-b±√(b²-4ac))/(2a)`，`a≠0`。
[核心][代数] 判别式是什么？ :: `Δ=b²-4ac`；决定实根个数。
[核心][代数] 二次方程有两个、一个、无实根的条件是什么？ :: `Δ>0,Δ=0,Δ<0`。
[核心][代数] 韦达定理是什么？ :: 若根为`r,s`，则`r+s=-b/a,rs=c/a`。
[核心][代数] 已知根`r,s`的首一二次多项式是什么？ :: `(x-r)(x-s)=x²-(r+s)x+rs`。
[核心][代数] 二次函数`ax²+bx+c`的对称轴是什么？ :: `x=-b/(2a)`。
[核心][代数] 二次函数顶点纵坐标如何求？ :: 代入`x=-b/(2a)`，或配方。
[核心][代数] 配方的基本形式是什么？ :: `x²+bx=(x+b/2)²-b²/4`。
[核心][代数] 二次函数最大/最小值由什么决定？ :: 开口方向和顶点；`a>0`有最小值，`a<0`有最大值。
[提高][代数] 整系数二次方程何时有整数根？ :: 判别式需为完全平方，且求根公式分子能被`2a`整除。
[核心][代数] 因式定理是什么？ :: `P(r)=0`当且仅当`x-r`是`P(x)`的因式。
[核心][代数] 余式定理是什么？ :: `P(x)`除以`x-r`的余数为`P(r)`。
[提高][代数] 除以二次式时余式长什么样？ :: 次数低于2，即`ax+b`。
[提高][代数] 多项式恒等式如何确定未知系数？ :: 展开比较系数，或代入足够多个方便值。
[提高][代数] 多项式整值题常用什么技巧？ :: 相邻输入作差、模因式、余式定理或整数根限制。

## 指数、根式与分式

[核心][代数] 同底数幂相乘规则是什么？ :: `a^m a^n=a^{m+n}`。
[核心][代数] 幂的幂规则是什么？ :: (a^m)^n=a^{mn}（需a>0，或m、n都是整数）。
[核心][代数] 负指数是什么意思？ :: `a^{-n}=1/a^n`，`a≠0`。
[核心][代数] 零指数规则是什么？ :: `a^0=1`，`a≠0`。
[核心][代数] 分数指数如何解释？ :: a^{m/n}=ⁿ√(a^m)，需a≥0（或m/n已约简且n为奇数）。
[核心][代数] `√(a²)`等于什么？ :: `|a|`，不是总等于`a`。
[核心][代数] 根式相加何时能合并？ :: 化为相同根式因子后才可合并系数。
[核心][代数] 如何有理化`1/(√a+√b)`？ :: 乘共轭`√a-√b`。
[核心][代数] 分式拆项的常见望远镜结构是什么？ :: `1/[n(n+1)]=1/n-1/(n+1)`。
[提高][代数] `1/[(n+a)(n+b)]`如何拆？ :: 写成1/(b-a) · (1/(n+a)-1/(n+b))，需b≠a。
[核心][代数] 指数方程首选什么方法？ :: 尽量化成相同底数，再比较指数。
[提高][代数] 根式和为单个根式时应检查什么？ :: 平方后交叉项是否为整数/同类根式，并验原式正负。

## 函数与图像

[核心][函数] 函数的定义是什么？ :: 每个允许输入对应唯一输出。
[核心][函数] 定义域是什么？ :: 所有允许输入的集合。
[核心][函数] 值域是什么？ :: 所有可能输出的集合。
[核心][函数] `f(a)`是什么意思？ :: 把输入`a`代入函数规则；不是`f·a`。
[核心][函数] 复合函数`f(g(x))`如何计算？ :: 先算内层`g(x)`，再把结果输入`f`。
[核心][函数] 反函数存在的关键条件是什么？ :: 在所讨论定义域上一一对应。
[核心][函数] 图像`y=f(x)+k`如何移动？ :: 竖直上移`k`；`k<0`则下移。
[核心][函数] 图像`y=f(x-h)`如何移动？ :: 水平右移`h`；括号内方向相反。
[核心][函数] `y=-f(x)`和`y=f(-x)`分别是什么反射？ :: 前者关于x轴，后者关于y轴。
[核心][函数] 偶函数的判定是什么？ :: `f(-x)=f(x)`，图像关于y轴对称。
[核心][函数] 奇函数的判定是什么？ :: `f(-x)=-f(x)`，图像关于原点中心对称。
[核心][函数] 两图像交点如何求？ :: 联立输出，即解`f(x)=g(x)`。
[提高][函数] 函数迭代是什么意思？ :: `f^{(n)}(x)`表示重复复合，不是通常意义的`[f(x)]^n`。
[提高][函数] 分段函数的关键检查是什么？ :: 输入属于哪一段，以及端点等号归属。
[提高][函数] 图像变换是否可交换？ :: 通常不可；必须按复合顺序追踪一个一般点。

## 数列与递推

[核心][数列] 等差数列通项是什么？ :: `a_n=a_1+(n-1)d`。
[核心][数列] 等差数列前`n`项和是什么？ :: `S_n=n(a_1+a_n)/2=n[2a_1+(n-1)d]/2`。
[核心][数列] 等比数列通项是什么？ :: `a_n=a_1r^{n-1}`。
[核心][数列] 等比数列前`n`项和是什么？ :: `S_n=a_1(1-r^n)/(1-r)`，`r≠1`。
[核心][数列] 无穷等比级数何时收敛？ :: `|r|<1`，和为`a_1/(1-r)`。
[核心][数列] 递推数列第一步应做什么？ :: 列前若干项，寻找周期、单调、奇偶或不变量。
[核心][数列] 索引最常见错误是什么？ :: 把第`n`项误写为经历`n`次变化；通常从`a_1`到`a_n`有`n-1`步。
[提高][数列] 一阶线性递推`a_{n+1}=ra_n+c`如何找平衡点？ :: 解L=rL+c（需r≠1，r=1时退化为等差），再研究a_n-L的等比变化。
[提高][数列] 周期递推如何求巨大下标？ :: 确定完整周期及起点，再对下标偏移取模。
[提高][数列] 望远镜求和的识别信号是什么？ :: 相邻项分解后大部分正负抵消。
[提高][数列] Fibonacci型递推常用什么策略？ :: 列项、模周期、相邻项关系和部分和恒等式。

## 不等式与最值

[核心][不等式] 乘除负数时不等号如何变化？ :: 方向反转。
[核心][不等式] 解有理不等式为什么不能直接乱乘分母？ :: 分母符号未知；应移到一边并作符号分析。
[核心][不等式] 三角不等式的数轴形式是什么？ :: |x-a|+|x-b|≥|a-b|，等号当且仅当x在a与b之间（此时取最小值|a-b|）。
[核心][不等式] 二元AM-GM是什么？ :: 对`x,y≥0`，`(x+y)/2≥√xy`，等号在`x=y`。
[核心][不等式] 固定和时乘积何时最大？ :: 非负变量尽量相等时。
[核心][不等式] 固定积时和何时最小？ :: 正变量尽量相等时。
[提高][不等式] 多元AM-GM是什么？ :: 非负数的算术平均不小于几何平均，等号在所有数相等。
[提高][不等式] 加权AM-GM的实战替代技巧是什么？ :: 按指数复制变量，如控制`x²y`就考虑`x,x,y`。
[核心][不等式] Cauchy平方和形式是什么？ :: (Σa_i²)(Σb_i²)≥(Σa_ib_i)²，等号当且仅当两组数成比例。
[核心][不等式] `n`个数的平方和下界是什么？ :: `Σx_i²≥(Σx_i)²/n`，等号在全部相等。
[提高][不等式] Titu/Engel形式是什么？ :: 正分母下，Σa_i²/x_i≥(Σa_i)²/(Σx_i)，等号当且仅当a_i/x_i全相等。
[核心][不等式] `1/x+1/y`在`x+y=S`时的下界是什么？ :: `4/S`，正数且`x=y`时取等。
[提高][不等式] QM-AM是什么？ :: 均方根不小于算术平均：√(Σa_i²/n)≥Σa_i/n（对任意实数成立），等号当且仅当所有数相等且公共值≥0；是Cauchy的直接结果。
[提高][不等式] 线性式在固定平方和下如何最大化？ :: 用Cauchy；变量向系数向量成比例时取等。
[核心][不等式] 连续最值用于整数题后还要做什么？ :: 检查最邻近整数、实际因数对和同余可达性。
[核心][不等式] 整数平滑原则是什么？ :: 固定和时若两数相差至少2，把大数减1、小数加1通常增大乘积。
[核心][不等式] 最值题必须写出的两件事是什么？ :: 界限证明和达到该界的合法取等例子。
[提高][不等式] 配方与AM-GM如何选择？ :: 二次式优先配方；非负固定和/积结构可用AM-GM。
[边界][不等式] Jensen、Holder、Muirhead是否为AMC 10优先内容？ :: 不是；先熟练配方、AM-GM、Cauchy、Titu和整数可达性。

## 查漏补充｜代数结构、统计与方法反向识别

[核心][代数] 一元一次方程`ax+b=c`在`a≠0`时的解是什么？ :: `x=(c-b)/a`。
[核心][代数] 恒等式、方程和条件式有什么区别？ :: 恒等式对定义域内所有值成立；方程只对解成立；条件式在给定条件下成立。
[核心][代数] 比例链`a:b=c:d`处理时最重要的条件是什么？ :: 分母非零，并明确哪些量共享同一比例因子。
[核心][代数] 立方和公式是什么？ :: `a³+b³=(a+b)(a²-ab+b²)`。
[核心][代数] 立方差公式是什么？ :: `a³-b³=(a-b)(a²+ab+b²)`。
[核心][代数] 分组因式分解的触发信号是什么？ :: 四项或多项能分组提取相同二项式因子。
[提高][代数] 根的重数是什么意思？ :: `(x-r)^k`整除多项式而更高次不整除时，`r`是`k`重根。
[提高][代数] 多项式除以`(x-a)(x-b)`且`a≠b`时如何确定线性余式？ :: 设余式`R(x)=mx+n`，用`R(a)=P(a),R(b)=P(b)`求系数。
[提高][代数] 首项系数不为1的有理根候选是什么？ :: 既约根`p/q`满足`p|常数项,q|首项系数`。
[核心][代数] 二项式定理是什么？ :: `(x+y)^n=Σ_{k=0}^n C(n,k)x^{n-k}y^k`。
[核心][代数] `(x+y)^n`中`x^{n-k}y^k`的系数是什么？ :: `C(n,k)`。
[提高][代数] 二项式展开的偶数项或奇数项系数和如何求？ :: 比较`(1+1)^n`与`(1-1)^n`，两者均为`2^{n-1}`（`n≥1`）。
[核心][不等式] `|x-a|<r`和`|x-a|≤r`分别表示什么？ :: 分别是`a-r<x<a+r`与`a-r≤x≤a+r`。
[核心][不等式] `|x-a|>r`表示什么？ :: `x<a-r`或`x>a+r`，前提`r≥0`。
[核心][不等式] 二次不等式如何用符号表求解？ :: 找零点与不可取点，按区间判断因子符号并处理端点。
[提高][不等式] 平方非负如何制造常用界？ :: 从`(x-y)²≥0`得到`x²+y²≥2xy`，或从`(x-a)²≥0`配方。
[提高][不等式] 判别式如何用于参数最值？ :: 把条件写成关于某变量的二次方程；存在实解要求`Δ≥0`，边界常在`Δ=0`。
[提高][不等式] 重排不等式的直观版本是什么？ :: 两个同向排序序列的对应乘积和最大，反向配对最小；极值在排序完全一致/完全相反时取到。
[提高][不等式] 单调函数在闭区间上的最值通常在哪里检查？ :: 若能证明单调，只需检查端点。
[提高][不等式] 凸二次函数在整数点上的最小值如何找？ :: 先找实数顶点，再检查其两侧最近整数。
[核心][函数] 线性函数`y=mx+b`中`m,b`分别表示什么？ :: 斜率和y轴截距。
[核心][函数] 函数的零点是什么？ :: 使`f(x)=0`的输入，即图像与x轴的交点横坐标。
[核心][函数] 反函数如何从方程求？ :: 写`y=f(x)`，交换`x,y`后解出`y`，并检查一一性与定义域。
[提高][函数] 水平伸缩`y=f(bx)`如何理解？ :: 横坐标按`1/|b|`缩放；`b<0`还关于y轴反射。
[提高][函数] 函数方程题的常用代入是什么？ :: 代0、1、相等变量、相反数或令内层表达式取特殊值。
[核心][统计] 平均数、中位数、众数分别反映什么？ :: 平均数用全部数值；中位数反映排序中心；众数反映最高频值。
[核心][统计] 哪个统计量最容易受极端值影响？ :: 平均数；中位数通常更稳健。
[核心][统计] 方差/离均差平方和为什么非负？ :: 每个`(x_i-x̄)²≥0`，总和至少为0且全相等时为0。
[核心][统计] 从频数表求平均数如何做？ :: `Σ(数值×频数)/总频数`。
[核心][统计] 直方图与条形图的关键区别是什么？ :: 直方图表示数值区间且柱通常相连；条形图表示类别。
[提高][数列] 混合等差等比数列如何识别？ :: 检查相邻差、相邻比、奇偶子序列或分块规则，不要强套单一模型。
[提高][数列] 二维递推表常如何处理？ :: 从边界开始按规则填小表，寻找Pascal型加法、对称或路径计数解释。
[提高][数列] 部分和`S_n`与通项有什么关系？ :: `a_n=S_n-S_{n-1}`（`n≥2`），且`a_1=S_1`。
