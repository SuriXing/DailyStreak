# Flashcards｜组合、概率、期望与随机过程

## 计数基础

[核心][组合] 加法原理何时使用？ :: 互斥情形“或”发生时，总数相加。
[核心][组合] 乘法原理何时使用？ :: 分阶段完成且每阶段选择数明确时，总数相乘。
[核心][组合] 为什么计数前要判断有序还是无序？ :: 同一批对象的排列和选择数量不同，决定用排列还是组合。
[核心][组合] `n!`是什么？ :: `n(n-1)...1`，且`0!=1`。
[核心][组合] 从`n`个不同对象取`r`个排列数是多少？ :: `P(n,r)=n!/(n-r)!`。
[核心][组合] 从`n`个不同对象取`r`个组合数是多少？ :: `C(n,r)=n!/[r!(n-r)!]`。
[核心][组合] 组合数对称性是什么？ :: `C(n,r)=C(n,n-r)`。
[核心][组合] Pascal恒等式是什么？ :: `C(n,r)=C(n-1,r-1)+C(n-1,r)`。
[核心][组合] 二项式系数和是多少？ :: `ΣC(n,r)=2^n`。
[核心][组合] 有重复元素的全排列数是多少？ :: `n!/(a!b!...)`，分母除去相同元素内部交换。
[核心][组合] 圆排列与直线排列有什么区别？ :: 只把旋转视为相同的`n`个不同对象圆排列为`(n-1)!`。
[提高][组合] 若反射也视为相同，能直接再除2吗？ :: 只有所有构型在反射作用下成大小一致的配对时才可；有对称固定构型需单独处理。
[核心][组合] “至少一个”计数首选什么？ :: 补集：总数减一个都没有。
[核心][组合] 容斥原理两集合形式是什么？ :: `|A∪B|=|A|+|B|-|A∩B|`。
[提高][组合] 三集合容斥的符号规律是什么？ :: 单集加、两两交减、三者交加。
[核心][组合] 分类讨论必须满足什么？ :: 各类互斥且覆盖全部可能。
[核心][组合] 固定特殊对象位置有什么用？ :: 消除旋转、对称或复杂邻接带来的重复计数。
[核心][组合] 相邻对象捆绑法是什么？ :: 把必须相邻的若干对象当作一个块，再乘块内排列。
[核心][组合] 禁止相邻常用什么方法？ :: 先排一类对象形成空隙，再把另一类放入空隙。
[核心][组合] 星与条解决什么问题？ :: 相同物品分入不同盒子的非负或正整数解计数。
[核心][组合] `x₁+...+x_k=n`的非负整数解个数是多少？ :: `C(n+k-1,k-1)`。
[核心][组合] `x₁+...+x_k=n`的正整数解个数是多少？ :: `C(n-1,k-1)`，要求`n≥k`。
[核心][组合] 有上界的星与条如何处理？ :: 容斥、生成空位后的分类，不能直接套无限制公式。
[提高][组合] 数字串计数第一位要怎样处理？ :: 单独限制首位不能为0，再处理其余位。
[提高][组合] 单调数字串如何转成组合？ :: 严格单调对应选集合；允许重复时可转为多重组合。

## 结构计数与证明

[核心][组合] 抽屉原理是什么？ :: 多于`kn`个对象放入`n`盒，至少一盒有`k+1`个；基本版为`n+1`入`n`。
[核心][组合] 双计数是什么？ :: 用两种方式计算同一组对象或关联对，建立等式。
[核心][组合] 图中所有顶点度数之和是什么？ :: `2E`，即握手定理。
[核心][组合] 树的基本边数关系是什么？ :: 有`V`个顶点的连通无环图有`V-1`条边。
[提高][组合] 网格最短路径数如何求？ :: 若需`a`步横向、`b`步纵向，则为`C(a+b,a)`，有障碍时分类或相减。
[核心][组合] 递推计数适合什么结构？ :: 当前选择只依赖少数前一状态，如不能连续、铺砖或局部染色。
[核心][组合] 状态设计的原则是什么？ :: 只记录决定下一步所需的最少信息。
[提高][组合] 不变量在组合过程题中做什么？ :: 找每步都不变的奇偶、模数、颜色和或置换性质，用于判不可能。
[提高][组合] 单调量（monovariant）每步单调变化有什么用？ :: 证明过程终止或给出步数上下界。
[核心][组合] 构造＋上界如何证明极值？ :: 先给达到`k`的例子，再证明任何合法对象都不超过`k`。
[提高][组合] sum-free集合的典型定义是什么？ :: 集合中不存在`x,y,z`满足`x+y=z`，是否允许`x=y`须按题意。
[提高][组合] 染色题常见方法是什么？ :: 先用对称固定一个颜色，再按邻接/局部状态分类，并检查颜色是否有标签。
[提高][组合] 对称等价计数的第一步是什么？ :: 明确旋转、反射或颜色置换中哪些操作视为相同。
[提高][组合] Burnside思想是什么？ :: 等价类数=(1/|G|)Σ_{g∈G}Fix(g)，G必须是含恒等元、对复合封闭的对称操作群；AMC 10只在普通分类很乱时用。
[提高][组合] inclusion-exclusion和递推如何选择？ :: 禁止若干全局事件适合容斥；局部相邻限制通常适合递推/状态。

## 概率

[核心][概率] 等可能有限样本空间中的概率公式是什么？ :: `有利结果数/总结果数`。
[核心][概率] 使用“有利/总数”前必须确认什么？ :: 基本结果确实等可能。
[核心][概率] 补事件公式是什么？ :: `P(A^c)=1-P(A)`。
[核心][概率] 并事件公式是什么？ :: `P(A∪B)=P(A)+P(B)-P(A∩B)`。
[核心][概率] 条件概率公式是什么？ :: `P(A|B)=P(A∩B)/P(B)`，`P(B)>0`。
[核心][概率] 独立事件的定义是什么？ :: `P(A∩B)=P(A)P(B)`。
[核心][概率] 互斥与独立相同吗？ :: 不同；正概率互斥事件不独立。
[核心][概率] 无放回抽取为何通常不独立？ :: 前一次结果改变后续样本空间。
[核心][概率] 至少一次成功如何计算？ :: `1-P(一次都不成功)`。
[核心][概率] `n`次独立Bernoulli试验恰好`k`次成功概率是什么？ :: `C(n,k)p^k(1-p)^{n-k}`。
[核心][概率] 全概率思想是什么？ :: 按互斥且完备的情形分解目标概率并加总。
[提高][概率] Bayes反推的核心是什么？ :: 用`P(A|B)=P(B|A)P(A)/P(B)`，分母由所有产生`B`的路径组成。
[核心][概率] 条件发生后样本空间怎样变化？ :: 只保留满足条件的结果，并重新归一化概率。
[核心][概率] 随机排列中某个指定对象位于指定位置的概率是多少？ :: `1/n`。
[核心][概率] 随机排列中两个指定对象相邻的概率是多少？ :: `2/n`。
[提高][概率] 几何概率的基本公式是什么？ :: 在面积均匀选点时为有利区域面积/总区域面积。
[核心][概率] “半径均匀”与“圆盘内均匀”相同吗？ :: 不同；随机机制决定密度。
[提高][概率] 连续概率边界线本身通常贡献多少概率？ :: 面积模型中为0，但边界仍决定区域划分。

## 期望

[核心][期望] 离散随机变量期望的定义是什么？ :: `E(X)=ΣxP(X=x)`。
[核心][期望] 期望一定是可能出现的结果吗？ :: 不一定；它是长期平均。
[核心][期望] 期望线性是什么？ :: `E(X+Y)=E(X)+E(Y)`。
[核心][期望] 期望线性要求独立吗？ :: 不要求。
[核心][期望] 指示变量是什么？ :: 事件发生取1，否则取0；其期望等于事件概率。
[核心][期望] 计数型随机变量如何用指示变量拆？ :: `X=ΣI_i`，所以`E(X)=ΣP(I_i=1)`。
[核心][期望] 随机排列固定点数的期望是多少？ :: 对`n`个对象始终是1。
[核心][期望] 盒子非空数的期望如何求？ :: 对每个盒子设“非空”指示变量，求其非空概率后相加。
[核心][期望] 相邻成功对数量为何可直接逐对相加？ :: 每一对设指示变量；重叠导致相关但不影响线性期望。
[提高][期望] 非负整数变量的尾和公式是什么？ :: `E(X)=Σ_{k≥1}P(X≥k)`。
[提高][期望] 最大值期望如何处理？ :: 列`P(M=m)`或使用尾和`ΣP(M≥k)`。
[提高][期望] 第一事件发生所需试验次数的期望如何列式？ :: 设E，按第一步列E=1+失败概率·E；只在各次独立且成功概率恒为p时解得E=1/p，概率随轮次变化要用带状态的方程E_s=1+ΣP(s→t)E_t。

## 随机过程

[提高][随机过程] 第一步分析/first-step analysis是什么？ :: 按下一步可能状态分类，写`p_s=ΣP(s→t)p_t`或相应期望方程。
[提高][随机过程] 吸收随机过程先写什么？ :: 成功、失败等边界状态的概率或期望值。
[提高][随机过程] 公平一维随机游走先到右端的概率是什么形状？ :: 在两个吸收端点之间随起点位置线性变化。
[提高][随机过程] 从0到`N`、起点`i`的公平游走先到`N`概率是多少？ :: `i/N`。
[提高][随机过程] 状态递推解完后要检查什么？ :: 概率是否在0到1之间、边界是否满足、状态是否遗漏。
[提高][概率] 相关事件能否使用乘法概率？ :: 只能用条件乘法`P(A∩B)=P(A)P(B|A)`；独立时才简化。
[提高][概率] 占用问题中盒子人数分布是否等可能？ :: 通常不等可能；应从每个对象的等可能选择或多项分配计数。
[提高][概率] 骰子点数和是否等可能？ :: 不等可能；中间和对应更多有序结果。

## 查漏补充｜近年结构与进阶计数概率

[核心][组合] 多项式系数/多类排列公式是什么？ :: 把`n`个不同位置分成大小`n₁,...,n_k`的有标号组，数量为`n!/(n₁!...n_k!)`。
[核心][组合] 有标号盒子与无标号盒子为什么不同？ :: 交换盒子若产生新结果则有标号；无标号分组需再处理组的交换重复。
[提高][组合] 把`n`个不同对象分成若干指定大小的无标号组怎样去重？ :: 先按有标号组计数，再除以大小相同的组之间的排列阶乘。
[提高][组合] 整数分拆与整数解有什么区别？ :: 分拆不计加数顺序；方程的有标号变量通常计顺序。
[核心][组合] 排列中的逆序对是什么？ :: 一对位置`i<j`却有`a_i>a_j`。
[提高][组合] 相邻交换会怎样改变逆序对数？ :: 恰好改变1，因此逆序对奇偶性翻转。
[核心][组合] `n`人循环赛每两人比赛一次共有多少场？ :: `C(n,2)`。
[提高][组合] 圆上`n`点无三弦共点时弦的内部交点数是多少？ :: 每4个点决定一个交点，所以为`C(n,4)`。
[提高][组合] 平面中若逐条加入曲线/直线，区域数如何递推？ :: 新曲线被已有交点分成几段，就新增几块区域；必须检查交点一般位置。
[提高][组合] 错排是什么？ :: 没有任何对象回到原位置的排列；小规模可容斥或递推。
[提高][组合] 错排递推是什么？ :: `D_n=(n-1)(D_{n-1}+D_{n-2})`，`D_0=1,D_1=0`。
[提高][组合] Catalan型结构的识别信号是什么？ :: 前缀始终不越界的路径、合法括号或非交叉结构；不是AMC 10基础必背。
[提高][组合] 反链是什么？ :: 集合族中任意两个集合都不互为包含；中间层常给最大构造。
[提高][组合] 排名允许并列时如何计数？ :: 先选并列分块/人员，再排列有序名次块；必须明确是否跳过后续名次。
[提高][组合] 局部染色如何建立状态？ :: 记录下一步仍会受影响的边界颜色/相等关系，不保存完整历史。
[核心][概率] 超几何概率描述什么？ :: 从含`K`个成功对象的`N`个对象中无放回取`n`个，恰好`k`个成功概率为`C(K,k)C(N-K,n-k)/C(N,n)`。
[提高][概率] 多项分配概率是什么？ :: 独立试验落入多类，计数为多项式系数乘各类概率的相应幂。
[核心][概率] 随机选一个约数时为什么不能按约数大小区间直接假设均匀？ :: 均匀的是约数列表中的对象；应先枚举质因数指数组合。
[提高][概率] 全概率公式是什么？ :: 对完备互斥事件`B_i`，`P(A)=ΣP(A|B_i)P(B_i)`。
[提高][概率] 条件期望的分层公式是什么？ :: `E(X)=ΣE(X|B_i)P(B_i)`。
[提高][期望] 期望乘积何时可拆？ :: `X,Y`独立时`E(XY)=E(X)E(Y)`；一般不能拆。
[提高][期望] 方差定义是什么？ :: `Var(X)=E[(X-E X)²]=E(X²)-[E(X)]²`。
[提高][期望] Bernoulli变量的期望与方差是什么？ :: 若成功概率`p`，则期望`p`、方差`p(1-p)`。
[提高][期望] 最小值的尾部如何处理？ :: 可由`P(min≥k)`求尾和，或先求最大/补变量的分布。
[提高][随机过程] 吸收时间期望的第一步方程是什么？ :: 非终止状态`E_s=1+ΣP(s→t)E_t`，终止状态期望为0。
[提高][随机过程] 状态具有对称性时如何降维？ :: 把未来行为完全相同的状态合并，写同一个未知量。
[提高][概率] 淘汰赛晋级概率如何递推？ :: 按下一场对手/胜负分类，将当前轮概率乘后续条件概率并相加。
[提高][概率] 条件概率中“已知最终成功”为什么会改变早期分支概率？ :: 不同早期分支通向最终成功的概率不同，需用Bayes重新加权。
