# 本地题库（放你自己的题，永远不会被发布）

这个仓库是公开的，题目的英文文本还会打进站点 bundle，所以**任何放进仓库的题都会被发布出去**。
MAA 的 AMC 题、College Board 的 AP 题都有版权，不适合公开。

但你自己练真题是完全合理的。为此留了一个本地专用入口：

```
content/local/          ← 你放题目（.gitignore 已排除）
public/local-deck.json  ← 脚本生成的产物（.gitignore 已排除）
```

App 在运行时请求 `/local-deck.json`：**本机开发服务器能取到，公开站点上是 404**，所以这条路
不会把任何内容带进仓库或部署产物。

## 用法

```bash
# 1. 把题目写成 markdown，放进 content/local/
mkdir -p content/local

# 2. 打开开关（写在 .env.local，该文件已被 .gitignore 排除）
echo 'EXPO_PUBLIC_LOCAL_DECK=1' >> .env.local

# 3. 生成 JSON
npm run bank:local

# 4. 起本地服务，练习页的卡组筛选里会多出「本地题库」
npm run web
```

**为什么要有这个开关**：App 默认不去请求这个文件。因为"文件不存在"本身会在浏览器控制台留下
一条 404，而仓库的冒烟测试断言零控制台错误——默认去试一个多半不存在的文件，等于给所有环境
（包括线上）加噪声。开关只写在本机、不进部署，正好和"只在本地练"是一件事。

## 文件格式

每行一题，支持仓库里已有的两种写法（逐个文件自动判断）：

```
41. 题干？ A. 选项 B. 选项 C. 选项 D. 选项
42. 题干？ A 选项 B 选项 C 选项 D 选项
```

答案有两种给法：

1. **写在同行末尾**：`42. 题干？ A 选项 B 选项 C 选项 D 选项 [答案 A]`
2. **写在同目录的 `<文件名>-answers.md`**，两种格式都认：
   - 表格：`|41|B|一句话解析|`
   - 行内：`41 B（一句话解析）;`

文件开头的 `# 标题` 会作为卡组名显示在练习页；没有就用「本地题库」。

## 为什么不会被发布

| 检查 | 结果 |
|---|---|
| `content/local/` 是否被 git 忽略 | ✅（`git check-ignore -v content/local/foo.md`） |
| `public/local-deck.json` 是否被忽略 | ✅ |
| App 是否把它打进 bundle | ❌ 不打：走运行时 `fetch('/local-deck.json')`，拿不到就当作没有这个卡组 |
| 公开站点上会怎样 | 该路径 404，练习页不显示「本地题库」 |

换句话说：**只要不手动 `git add -f`，这些题就不可能出现在仓库或线上**。

## 其他说明

- 本地题的来源在卡片上标为「本地题库（未公开）」，并且一律标为**未核验**——本仓库没有复核过它们。
- `npm run bank:local` 每次都会重写 `public/local-deck.json`，所以删掉 `content/local/` 里的题后重跑即可清空。
