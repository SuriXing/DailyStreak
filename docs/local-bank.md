# 本地题库（放你自己的题，永远不会被发布）

这个仓库是公开的，题目的英文文本还会打进站点 bundle，所以**任何放进仓库的题都会被发布出去**。
MAA 的 AMC 题、College Board 的 AP 题都有版权，不适合公开。

但你自己练真题是完全合理的。为此留了一个本地专用入口：

```
content/local/          ← 你放题目（.gitignore 已排除）
public/local-deck.json  ← 脚本生成的产物（.gitignore 已排除）
```

App 在运行时请求 `/local-deck.json`：**本机开发服务器能取到，公开站点上是 404**，所以这条路
不会把任何内容带进仓库或部署产物。

## 用法

```bash
# 1. 把题目写成 markdown，放进 content/local/
mkdir -p content/local

# 2. 打开开关（写在 .env.local，该文件已被 .gitignore 排除）
echo 'EXPO_PUBLIC_LOCAL_DECK=1' >> .env.local

# 3. 生成 JSON
npm run bank:local

# 4. 起本地服务，练习页的卡组筛选里会多出「本地题库」
npm run web
```

**为什么要有这个开关**：App 默认不去请求这个文件。因为"文件不存在"本身会在浏览器控制台留下
一条 404，而仓库的冒烟测试断言零控制台错误——默认去试一个多半不存在的文件，等于给所有环境
（包括线上）加噪声。开关只写在本机、不进部署，正好和"只在本地练"是一件事。

## 文件格式

每行一题，支持仓库里已有的两种写法（逐个文件自动判断）：

```
41. 题干？ A. 选项 B. 选项 C. 选项 D. 选项
42. 题干？ A 选项 B 选项 C 选项 D 选项
```

答案有两种给法：

1. **写在同行末尾**：`42. 题干？ A 选项 B 选项 C 选项 D 选项 [答案 A]`
2. **写在同目录的 `<文件名>-answers.md`**，两种格式都认：
   - 表格：`|41|B|一句话解析|`
   - 行内：`41 B（一句话解析）;`

文件开头的 `# 标题` 会作为卡组名显示在练习页；没有就用「本地题库」。

## 难度（可选）

难度**不写也能练**，写了才会被练习页的「难度分级」筛选与「由易到难 / 由难到易」排序认出来。
写法是行尾的方括号标记，取值 1-4，与内置题库的 rubric 同一口径（见 [docs/difficulty-rubric.md](difficulty-rubric.md)）：

```
1. 题干？ A. 选项 B. 选项 C. 选项 D. 选项 [难度 3] [答案 B]
2. 题干？ A 选项 B 选项 C 选项 D 选项 [答案 C] [难度：1]
3. 题干？ A 选项 B 选项 C 选项 D 选项 [难度 4]
```

- `[难度 3]`、`[难度：3]`、`[难度3]`、`[difficulty 3]` 都认（空格、全角/半角冒号、大小写随意）。
- 难度与答案两个标记**顺序任意**：`[难度 3] [答案 B]` 和 `[答案 B] [难度 3]` 等价；
  难度可以单独写（答案照旧放进 `<文件名>-answers.md`）。
- 1 最简单、4 最难，与内置题的四档叫法一致，卡片上会显示成「难度 3」。

### 不写难度会怎样

不写就是**没有分级**，而不是"难度 0"——和内置题库里那批 AMC10 概念卡一个待遇：

| 位置 | 表现 |
|---|---|
| `public/local-deck.json` | 那张卡连 `difficulty` 字段都没有（不是 `0`，也不是 `null`） |
| 卡片上的难度标签 | 不显示（不会编出「难度 0 / 难度 undefined」） |
| 练习页的「难度分级」 | 选中任何一档都不出现（它没有"难度"这个维度，不是被算成某一档） |
| 「由易到难 / 由难到易」 | 排在所有带分级的卡**后面**，内部保持文件里的出题顺序 |
| 「我的」页题库概览 | 本地题库本来就不在概览里（默认关闭，开关只写在本机） |

所以**老文件一个字都不用改**：一个难度标记都不写时，生成出来的 JSON 与加这个功能之前完全一样。

有一点值得先知道：难度分级那一行只有在**至少两个档**时才显示（内置题库也是这个规则，只有一档就没有可筛的东西）。
所以如果选中「本地题库」卡组、而这份题库只标出了一个档位，界面上不会有那一行——卡上仍然带难度标签。

### 标错了会怎样

标了但读不出来（`[难度 5]`、`[难度 难]`、`[难度 ]`）会**跳过那道题**并打印原因，而不是当成"没写"：

```
⚠️ 跳过 2 行：
   - exam.md 第 12 题（难度 5 超出 1-4）
   - exam.md 第 13 题（难度标记读不出来，只认 [难度 1-4]）
```

为什么不静默降级成"没有分级"：标错和有意不标是两回事。偷偷降级的话，写错的人会以为难度已经生效，
在界面上按那一档却怎么也找不到这道题；跳过 + 打印至少当场看得见。生成成功时也会顺便报一下标了多少张：

```
✅ 本地题库：37 张 → public/local-deck.json（已被 .gitignore 排除，不会进仓库或部署）
   难度：29 张带分级、8 张没有分级（没标的卡不参与难度筛选与难度排序）
```

### 难度这块没做的

- **没有批量标注**：难度只能一题一行地手写。生成器不会按题干长度、选项数或文件名猜档位，
  也没有"整份文件默认难度 N"这种文件级标记——猜出来的档位会和内置题的可比性一起失真。
- 只有 1-4 四档，写 5 会被跳过（与内置题库一致），没有自定义档位或小数难度。

## 为什么不会被发布

| 检查 | 结果 |
|---|---|
| `content/local/` 是否被 git 忽略 | ✅（`git check-ignore -v content/local/foo.md`） |
| `public/local-deck.json` 是否被忽略 | ✅ |
| App 是否把它打进 bundle | ❌ 不打：走运行时 `fetch('/local-deck.json')`，拿不到就当作没有这个卡组 |
| 公开站点上会怎样 | 该路径 404，练习页不显示「本地题库」 |

换句话说：**只要不手动 `git add -f`，这些题就不可能出现在仓库或线上**。

## 其他说明

- 本地题的来源在卡片上标为「本地题库（未公开）」，并且一律标为**未核验**——本仓库没有复核过它们。
- 难度也是同样的态度：标了 `[难度 N]` 的本地卡会进入难度筛选与难度排序，但那个档位是**你自己判的**，
  没有经过本仓库的复核（内置题的 1-4 由 content/subject-banks/difficulty.json 逐题判定）。
- `npm run bank:local` 每次都会重写 `public/local-deck.json`，所以删掉 `content/local/` 里的题后重跑即可清空。
- 生成器认两个环境变量覆写路径：`LOCAL_BANK_SRC`（输入目录）、`LOCAL_BANK_OUT`（输出文件）。
  这是给 `scripts/test-session-logic.mjs` 的往返测试用的——它在临时目录里跑一遍生成器，
  免得把本机这份 `public/local-deck.json` 冲掉（那份文件不在仓库里，冲掉就真没了）。日常不用管它们。
