# Flashcards｜综合方法、策略与范围边界

## 建模与综合方法

[核心][方法] 文字题第一步是什么？ :: 定义变量并写单位，再把每句话翻译成关系式。
[核心][方法] 图形题第一步是什么？ :: 重画清晰图，标已知、等长、平行、直角和目标量；不依赖比例尺。
[核心][方法] 复杂题如何寻找不变量？ :: 比较操作前后不变的奇偶、和、积、余数、颜色或距离关系。
[核心][方法] 对称性有什么直接用途？ :: 减少分类、确定相等量、固定代表或推出期望相同。
[核心][方法] 极端原则是什么？ :: 选最大、最小、最左等极端对象，利用其不能继续延伸的限制。
[核心][方法] 反证法结构是什么？ :: 假设结论不成立，推导与已知、定义或基本事实矛盾。
[核心][方法] 构造题怎样证明答案确实最优？ :: 同时给合法构造和与方向匹配的界：求最大值证不可超过的上界，求最小值证不可低于的下界。
[核心][方法] 测试小规模有什么用？ :: 发现模式、检验猜想和边界；不能替代一般证明。
[核心][方法] 代答案什么时候有效？ :: 选择题中选项简单、方程逆解麻烦且能快速排除时。
[核心][方法] 取特殊值什么时候安全？ :: 用于排除恒等式或发现规律；证明一般结论仍需覆盖全部情况。
[核心][方法] 维度分析能排除什么？ :: 单位或次数错误，如面积答案却具有长度单位。
[提高][方法] 齐次性有什么用？ :: 所有项同次数时可按比例缩放，常可令某个和、积或长度为1。
[提高][方法] 双向夹逼完成最值的结构是什么？ :: 先证明目标`≤M`或`≥m`，再给等号可达实例。
[提高][方法] 代数题几何化的常见信号是什么？ :: 出现距离根式、平方和、绝对值或固定和积。
[提高][方法] 几何题代数化的常见信号是什么？ :: 大量直角、平行、比例、坐标或规则变换。
[核心][方法] 多种解法如何选择？ :: 优先条件少、计算短、验根清楚且不易出错的方法。

## 英文触发词

[核心][英文] integer与whole number通常分别指什么？ :: integer为整数；whole number通常指非负整数，仍以题目定义为准。
[核心][英文] positive integer是否包含0？ :: 不包含。
[核心][英文] distinct是什么意思？ :: 互不相同。
[核心][英文] at least与at most是什么意思？ :: 至少`≥`；至多`≤`。
[核心][英文] no more than与no less than是什么意思？ :: 不超过`≤`；不少于`≥`。
[核心][英文] consecutive integers是什么意思？ :: 连续整数，相邻差1。
[核心][英文] factor、multiple、divisor分别是什么？ :: factor/divisor为因数；multiple为倍数。
[核心][英文] remainder是什么意思？ :: 余数，需满足通常的`0≤r<m`。
[核心][英文] chosen uniformly at random是什么意思？ :: 从指定基本结果中等概率选择。
[核心][英文] without replacement是什么意思？ :: 不放回，后续选择通常受前次影响。
[核心][英文] expected number是什么意思？ :: 某个计数型随机变量的期望，不是最可能数量。
[核心][英文] tangent、secant、chord分别是什么？ :: 切线、割线、弦。
[核心][英文] circumcircle与incircle是什么？ :: 外接圆与内切圆。
[核心][英文] perpendicular bisector是什么？ :: 垂直平分线。
[核心][英文] centroid、incenter、circumcenter、orthocenter是什么？ :: 重心、内心、外心、垂心。
[核心][英文] similar与congruent有什么区别？ :: 相似允许缩放；全等大小形状都相同。
[核心][英文] a figure is inscribed in a circle是什么意思？ :: 图形顶点在圆上。
[核心][英文] a circle is inscribed in a polygon是什么意思？ :: 圆与多边形各边相切。
[核心][英文] maximum possible与minimum possible要求什么？ :: 不仅算界，还要确认该界能被合法对象达到。
[核心][英文] not necessarily drawn to scale提醒什么？ :: 不能凭图目测长度、角度或相交位置。

## 考场执行

[核心][策略] AMC 10整卷结构是什么？ :: 25道五选一，通常75分钟；当年规则仍须在MAA官网确认。
[核心][策略] 第一轮做题目标是什么？ :: 快速完成确定会做的题，不让一道难题吞掉时间。
[核心][策略] 什么时候应暂时跳题？ :: 约2–3分钟仍无清晰进展、计算失控或模型尚未识别时。
[核心][策略] 涂卡前应检查什么？ :: 题号、选项、是否错位以及空题策略。
[核心][策略] 数值答案应做哪三项检查？ :: 符号、数量级、单位/范围。
[核心][策略] 几何答案应做什么合理性检查？ :: 长度为正、角度范围正确、面积不超过容器、比例符合图形关系。
[核心][策略] 概率答案的范围是什么？ :: 0到1；期望则不受此范围限制。
[核心][策略] 整数题最后要检查什么？ :: 正/非负要求、整除、奇偶、范围和是否重复计数。
[核心][策略] 错题分类至少有哪些？ :: 知识漏洞、模型识别、计算、读题、时间管理。
[核心][策略] 错题复测为何不能只看答案？ :: 熟悉答案不等于能独立重建解法；应闭卷重做并解释触发点。
[核心][策略] 推荐复测间隔是什么？ :: 约48小时、7天、21天，根据遗忘情况调整。

## 范围与优先级

[边界][范围] AMC 10核心数学范围是什么？ :: 初等代数、初等几何、数论、计数与概率及其综合问题。
[边界][范围] 微积分是否属于AMC 10必需范围？ :: 不属于。
[边界][范围] 三角函数是否属于AMC 10官方核心范围？ :: 不属于；特殊三角形和几何关系足够。
[边界][范围] 复数是否应作为优先专题？ :: 不是AMC 10备考优先内容，除非个人拓展。
[边界][范围] 高级不等式是否应先于基础方法？ :: 不应；AM-GM、Cauchy、Titu、配方、三角不等式和取等检查优先。
[边界][范围] Burnside、生成函数是否必须？ :: 不是；只作为少量高难对称/计数题的提高工具。
[边界][范围] 近五年低频是否等于不会考？ :: 不等于；频率用于分配训练，不是删减考纲或押题。
[边界][范围] Flashcards能否替代完整做题？ :: 不能；卡片负责记忆与识别，真题负责建模、计算和时间压力。

## 查漏补充｜逻辑、证明与卡片闭环

[核心][逻辑] 命题是什么？ :: 能明确判断真或假的陈述句。
[核心][逻辑] 命题`P`的否定是什么？ :: “`P`不成立”；否定必须覆盖`P`以外的全部情况。
[核心][逻辑] “所有对象都满足P”的否定是什么？ :: “至少存在一个对象不满足P”。
[核心][逻辑] “至少存在一个对象满足P”的否定是什么？ :: “所有对象都不满足P”。
[核心][逻辑] 蕴含`P→Q`什么时候为假？ :: 仅当`P`真而`Q`假。
[核心][逻辑] `P→Q`的逆命题是什么？ :: `Q→P`，不一定与原命题等价。
[核心][逻辑] `P→Q`的逆否命题是什么？ :: `非Q→非P`，与原命题等价。
[核心][逻辑] “P是Q的充分条件”是什么意思？ :: `P→Q`。
[核心][逻辑] “P是Q的必要条件”是什么意思？ :: `Q→P`。
[核心][逻辑] “当且仅当”要求证明什么？ :: 两个方向都成立。
[核心][逻辑] 一个反例能推翻什么？ :: “所有……都……”或“必然……”型全称命题。
[核心][逻辑] 一个例子能证明“可能”吗？ :: 能；但不能证明“总是”。
[核心][逻辑] 真假话题的稳健方法是什么？ :: 为每个人/陈述设真假状态，逐条翻译并排除矛盾。
[提高][逻辑] 自指陈述题先检查什么？ :: 假设它真或假是否分别自洽；不要凭语感判断。
[提高][逻辑] 信息推断题如何证明答案唯一？ :: 列出所有初始可能，逐条筛选，最后确认只剩一个。
[核心][证明] 直接证明的结构是什么？ :: 从已知出发，用定义和已知定理逐步推出结论。
[核心][证明] 分类证明怎样保证完整？ :: 分类条件互斥并覆盖所有可能，边界单独确认。
[提高][证明] 交换论证如何证明贪心选择不劣？ :: 把任一最优解的局部选择换成贪心选择，证明可行且目标不变差。
[提高][证明] 归纳法的两步是什么？ :: 验证基础情形；假设第`n`情形成立并推出第`n+1`情形。
[核心][策略] “会背公式但不会启动”应补哪类卡？ :: 补“题面结构→首选方法”的识别卡，而不是重复公式卡。
[核心][策略] 每张知识卡怎样连接做题？ :: 至少绑定一道例题/真题题号，并记录首次独立做对日期。
[核心][策略] 卡片回答到什么程度才算通过？ :: 不只说公式，还要说适用条件、取等/边界和一个典型触发词。
[核心][策略] 如何防止卡片过大？ :: 一张只问一个可独立判定的问题；定义、公式、条件、陷阱必要时拆开。
[核心][策略] 如何防止只会正向回忆？ :: 同一重要知识同时做“名称→公式”和“结构→方法”两种方向的卡。
